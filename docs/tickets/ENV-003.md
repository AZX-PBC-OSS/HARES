## Background/Context

Windows parsed as `Boundary` structs have `assembly_r_value_m2_k_w = None` and empty `r_value_layers_m2_k_w`. In `conversions.rs:52-59`, they fall through to `DEFAULT_R_M2_K_W` (2.5 m²K/W). For a typical window with U=2.1 W/m²K, the correct glass R ≈ 0.48 m²K/W — **HARES uses 5x the correct resistance**, making windows appear far more insulating than they are.

Additionally, generic TARP/DOE-2 film resistances are applied to windows. OCHRE uses EnergyPlus Simple Window Model Step 1:
- Interior film R = U-factor-dependent logarithmic fit
- **Exterior film R = 0** (per EnergyPlus convention — **CRITICAL**: must be explicitly set to 0.0, not derived)
- Glass R = 1/U - r_int

This also affects `solver_builder.rs:317-323` where `r_glass` is computed from `bd_input.r_film_interior_m2_k_w` — since the film R values are set in `BoundaryInput`, fixing them in `conversions.rs` automatically fixes `solver_builder.rs` with **no changes needed there**.

## Work to Do

- [ ] Add `window_u_factor_decomposition` to `crates/hares-physics/src/solar.rs` (alongside existing `calculate_window_parameters`):
  ```rust
  /// EnergyPlus Simple Window Model Step 1: U-factor → (r_glass, r_film_int).
  /// Exterior film = 0 for windows per EnergyPlus convention.
  pub fn window_u_factor_decomposition(u_factor_w_m2_k: f64) -> (f64, f64) {
      let r_int = if u_factor_w_m2_k < 5.85 {
          1.0 / (0.359073 * u_factor_w_m2_k.ln() + 6.949915)
      } else {
          1.0 / (1.788041 * u_factor_w_m2_k - 2.886625)
      };
      let r_glass = (1.0 / u_factor_w_m2_k - r_int).max(0.0);
      (r_glass, r_int)
  }
  ```
