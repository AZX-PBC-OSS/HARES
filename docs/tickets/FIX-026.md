# FIX-026: Gas WH pilot power defaults to 0 W

> **REVISED** (Codex review 2026-03-19): Reframed as physics enhancement, not OCHRE parity fix. OCHRE's `WaterHeater.py:705` does not set a pilot power default — the "3.5W" claim was not backed by vendored code. Severity lowered from HIGH to MEDIUM.

**Severity:** MEDIUM
**Crate:** `hares-equipment`
**File:** `crates/hares-equipment/src/water_heater/gas.rs`

---

## Issue

In `gas.rs` lines 304-306, pilot power defaults to zero:

```rust
// gas.rs:304-306
self.pilot_power_w = first_f64(config, &["pilot_power_w", "PilotPower"])
    .unwrap_or(0.0)
    .max(0.0);
```

A standing pilot gas water heater with 0 W pilot power reports zero standby gas consumption. The pilot flame on a typical atmospheric gas water heater consumes approximately 3-10 W (thermal) continuously. Over a year, this represents roughly 30-90 therms of gas — a meaningful fraction of total water heater gas consumption.

This is a **physics enhancement**, not an OCHRE parity fix. OCHRE's `WaterHeater.py:705` does not set a pilot power default either. Both OCHRE and HARES currently default to zero.

## Rationale

Standing pilot flames are a real energy consumer. If we want to model this for accuracy, it should be added as an optional parameter with a sensible default derived from DOE test procedures or manufacturer specifications. Typical values from DOE 10 CFR 430 test procedures and manufacturer data:

- Natural draft atmospheric: ~4-8 W thermal equivalent
- A reasonable central estimate: ~5 W (thermal)

## Fix

1. Add an optional pilot power parameter with a default derived from DOE test procedure data (not OCHRE):

```rust
/// Standing pilot flame power (thermal). Default from DOE 10 CFR 430
/// test procedure data for natural-draft atmospheric gas water heaters.
const DEFAULT_PILOT_POWER_W: f64 = 5.0;
```

2. Apply only when ignition type indicates a standing pilot (not electronic ignition):

```rust
let has_standing_pilot = first_str(config, &["ignition_type"])
    .map(|s| s == "standing_pilot")
    .unwrap_or(true); // assume standing pilot for older units

self.pilot_power_w = first_f64(config, &["pilot_power_w", "PilotPower"])
    .unwrap_or(if has_standing_pilot { DEFAULT_PILOT_POWER_W } else { 0.0 })
    .max(0.0);
```

3. Document the source of the default value in a code comment.

## Test

- **Unit test:** Create a gas WH with no `pilot_power_w` and no `ignition_type`. Verify `pilot_power_w == 5.0` (standing pilot assumed).
- **Unit test:** Create a gas WH with `ignition_type = "electronic"`. Verify `pilot_power_w == 0.0`.
- **Unit test:** Create a gas WH with explicit `pilot_power_w = 7.0`. Verify it uses 7.0 regardless of ignition type.
- **Standby test:** Step a standing-pilot gas WH for one hour with no draws and tank at setpoint. Verify gas consumption is non-zero.
