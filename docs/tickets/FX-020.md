## Status: INVALID — Closed by review

**HARES's pool-adjacent-violators (PAV) algorithm is provably superior to OCHRE's two-pointer heat-redistribution algorithm.** Do not replace it.

### Evidence

| Property | HARES (PAV) | OCHRE (two-pointer) |
|---|---|---|
| Energy conservation | Exact by construction (mass-weighted average) | Validated post-hoc via 1 J tolerance; can fail |
| Intermediate temperature validity | Always valid | Can produce unphysical intermediates (negative temps on small nodes) |
| Monotonicity guarantee | Single pass, provably correct | Relies on outer loop + early-exit heuristic |
| Algorithmic complexity | O(n) | O(n²) worst case |
| Dead-band tolerance | None (exact) | 0.001°C threshold introduces systematic bias |
| Alignment with EnergyPlus ref | Yes (weighted average of inverted nodes) | Approximate; differs from EP approach |

The PAV algorithm is the standard approach used in EnergyPlus for stratified tank inversion correction. OCHRE's algorithm is a numerically fragile approximation that can produce physically invalid intermediate states, evidenced by OCHRE's own `ModelException` error path.

### Action: Add deterministic PAV output test

The only real gap: add a deterministic fixture-based test verifying the PAV output for a complex multi-inversion case (not just monotonicity/energy-conservation, which are already tested).

### OCHRE Divergence Note

Node-by-node parity with OCHRE is explicitly not a goal here. Better physics wins.
