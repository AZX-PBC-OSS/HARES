## Background/Context

The Equipment trait needs a `core_output()` method so consumers can read typed
outputs. Adding a default implementation that returns a static empty CoreOutput
keeps the tree compiling while individual equipment types are migrated.

## Work to Do

- [ ] Add `fn core_output(&self) -> &CoreOutput` to the `Equipment` trait with a
      default implementation. Use a `once_cell::sync::Lazy` or `const` default:
      ```rust
      fn core_output(&self) -> &CoreOutput {
          static DEFAULT: CoreOutput = CoreOutput {
              flows: CoreFlows { electric_kw: None, reactive_power_kvar: None, fuel_w: None },
              state: CoreState { operating_mode: None, soc: None },
          };
          &DEFAULT
      }
      ```
- [ ] Add `core_output: CoreOutput` field to the existing `MockEquipment` test struct
      in lib.rs (if present) and implement the method returning `&self.core_output`.
- [ ] Verify all 20+ equipment types compile with the default stub.
