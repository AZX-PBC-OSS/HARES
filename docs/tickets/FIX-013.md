# FIX-013: Heat pump backup lockout temperature already extracted but verify wiring

> **STATUS: CLOSED — Invalid** (Codex review 2026-03-19)
> HP lockout temperatures already have correct defaults: compressor lockout at -17.78C (0F) and backup switchover at 4.44C (40F) in `heat_pump/constants.rs:35`. Parser fallback at `equipment.rs:201` matches OCHRE-style handling. No wiring issue exists.

**Severity:** HIGH

**Files:** `crates/hares-io/src/hpxml/equipment.rs`, `crates/hares-equipment/src/hvac/heat_pump/heater.rs`

## Bug

HPXML parsing DOES extract backup heating lockout temperatures (equipment.rs lines 202-224):

```rust
// equipment.rs:202-224
// Lockout temperatures (°F → °C)
for (xml_keys, param_key) in [
    (
        &["CompressorLockoutTemperature", "BackupHeatingSwitchoverTemperature"][..],
        "hp_lockout_temp_c",
    ),
    (
        &["BackupHeatingLockoutTemperature", "BackupHeatingSwitchoverTemperature"][..],
        "er_lockout_temp_c",
    ),
] { ... }
```

And the heat pump heater model (`heater.rs` lines 60-61) has lockout fields:

```rust
hp_lockout_temp_c: f64,
er_lockout_temp_c: f64,
```

However, when NEITHER `CompressorLockoutTemperature` NOR `BackupHeatingSwitchoverTemperature` is present in the HPXML (which is common for older files), no default is inserted. The heat pump model must default to a sensible value. OCHRE defaults the compressor lockout to 0 degF (-17.8 degC) and the ER upper lockout to 40 degF (4.4 degC).

The issue is that when these keys are absent from config, the heat pump model likely uses 0.0 degC or some other uninitialized default instead of OCHRE's values.

## OCHRE Reference

OCHRE `Equipment/HVAC.py` defaults:
- Compressor lockout: 0 degF = -17.8 degC (below this, compressor is off)
- ER lockout: 40 degF = 4.4 degC (above this, backup element is off)
- Backup switchover: same as compressor lockout if not specified

## Fix

1. In heat pump heater init, ensure defaults match OCHRE when config keys are absent:

```rust
const DEFAULT_HP_LOCKOUT_TEMP_C: f64 = -17.778; // 0°F
const DEFAULT_ER_LOCKOUT_TEMP_C: f64 = 4.444;   // 40°F
```

2. In HPXML parsing, insert default lockout temps when the HPXML element is absent, based on heat pump type (ASHP vs MSHP may differ).
