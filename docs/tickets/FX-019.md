## Background/Context

All storage WHs call `distribute_heat_to_nodes(...)` before `self.tank.step(...)`. Element heat is absorbed into node temps before draw displaces water, artificially inflating outlet temperature. OCHRE integrates heat injection and draw together in the same ODE step.

## Work to Do

- [ ] **Option A only** (Option B is physically incorrect — draw-then-heat understates end-of-step temperature and does not match OCHRE): Pass element heat injection as `heat_injections: &[(usize, f64)]` argument to `tank.step()` so draw and heating are integrated simultaneously in the Euler step
- [ ] **Critical**: `outlet_temp_c` must be snapshotted from the **pre-heating** top-node temperature. If heat injection is applied inside `tank.step()` before `apply_draw`, the outlet must use the pre-step node value. OCHRE sets `self.outlet_temp = self.states[self.t_1_idx]` from current (pre-update) state before any ODE step (Water.py:284)
- [ ] Update `tank.step()` signature — propagates to `resistance.rs`, `heat_pump_wh.rs`, `gas.rs`, and all tests calling `tank.step`
- [ ] Update both `resistance.rs` and `heat_pump_wh.rs` step functions to pass heat injections rather than calling `heat_node`/`distribute_heat_to_nodes` separately
- [ ] Add test: given a step with nonzero element power and nonzero draw, verify outlet temp under fixed code is lower (closer to pre-step tank temp) than under the current ordering
