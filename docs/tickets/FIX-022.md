# FIX-022: AC latent degradation parameters all default to 0.0

**Severity:** CRITICAL
**Crate:** `hares-equipment`
**File:** `crates/hares-equipment/src/hvac/air_conditioner.rs`

---

## Bug

In `air_conditioner.rs` lines 462-473, all four latent degradation parameters default to 0.0:

```rust
// air_conditioner.rs:462-473
self.latent_degradation = LatentDegradationParams {
    twet_rated_s: first_f64(config, &["twet_rated_s", "latent_twet_rated_s"])
        .unwrap_or(0.0),
    gamma_rated: first_f64(config, &["gamma_rated", "latent_gamma_rated"]).unwrap_or(0.0),
    max_cycling_rate: first_f64(config, &["max_cycling_rate", "latent_max_cycling_rate"])
        .unwrap_or(0.0),
    latent_time_constant_s: first_f64(
        config,
        &["latent_time_constant_s", "latent_capacity_time_constant_s"],
    )
    .unwrap_or(0.0),
};
```

With all parameters at 0.0, the latent degradation model is fully disabled. The AC reports full rated latent capacity at all part-load ratios and short cycles, which significantly overestimates moisture removal. This makes humidity predictions unreliable in cooling-dominated climates.

## OCHRE Reference

OCHRE `ochre/equipment/hvac.py` loads latent degradation parameters from `defaults/hvac_cooling/Air Conditioner.csv` (or the specific equipment CSV). The OCHRE defaults are approximately:

- `twet_rated_s` = 1000 (rated time to wet coil, seconds)
- `gamma_rated` = 1.5 (dimensionless ratio)
- `max_cycling_rate` = 3.0 (cycles per hour)
- `latent_time_constant_s` = 45 (seconds)

These values come from the Henderson-Rengarajan latent degradation model (ASHRAE RP-1120). With these defaults, latent capacity degrades at short cycle times and part-load, which matches real AC behavior.

## Fix

1. Define named constants for the OCHRE-aligned defaults:

```rust
const DEFAULT_TWET_RATED_S: f64 = 1000.0;
const DEFAULT_GAMMA_RATED: f64 = 1.5;
const DEFAULT_MAX_CYCLING_RATE: f64 = 3.0;
const DEFAULT_LATENT_TIME_CONSTANT_S: f64 = 45.0;
```

2. Replace the `.unwrap_or(0.0)` calls with these constants.
3. Alternatively, load from `defaults/hvac_cooling/Air Conditioner.csv` via the defaults mechanism.

## Test

- **Unit test:** Create an AC with no latent degradation parameters in config. Verify defaults are non-zero (`twet_rated_s == 1000.0`, etc.).
- **Unit test:** Create an AC with explicit latent params. Verify they override the defaults.
- **Physics test:** Step an AC at part-load ratio < 1.0 with default latent params. Verify latent capacity is less than rated latent capacity (degradation is active).
- **Regression test:** Step an AC at PLR = 1.0. Verify latent capacity equals rated latent capacity (no degradation at full load).
