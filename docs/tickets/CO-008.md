## Background/Context

A prior (wrong) approach added duplicate `electric_kw` telemetry writes to Battery,
EV, PV, Generator, and EventLoad. These must be reverted — each equipment writes
only its own semantically-correct telemetry key (active_power_kw, ac_power_kw,
electric_output_kw). The dwelling now reads CoreOutput, not telemetry strings.

Also remove the default stub from the Equipment trait since all equipment types
now have real implementations.

- [ ] EV: remove `electric_kw` insert/set/TelemetryField from telemetry.rs and mod.rs

- [ ] Generator: remove `electric_kw` insert/set/TelemetryField (keep `electric_output_kw`)
