## Background/Context

OCHRE scales delivered heat, electric power, fan power, and gas consumption by `space_fraction` (from HPXML `FractionCoolingLoadServed` / `FractionHeatingLoadServed`). HARES has no equivalent. Room AC covering 50% of floor area will overstate power by 2x.

## Work to Do

- [ ] Add `space_fraction: f64` field to `HvacEquipment` (default 1.0, clamped to [0.0, 1.0] with warning on out-of-range)
- [ ] Parse from HPXML with correct key lookup priority:
  - Heater: read `fraction_heating_load_served`, fall back to `fraction_load_served`
  - Cooler: read `fraction_cooling_load_served`, fall back to `fraction_load_served`
  - Note: for heat pumps split into heater/cooler, both share the same `params` map — each half must read the correct key
- [ ] **Scale only electrical/fuel port contributions and telemetry** by `space_fraction`. Do NOT scale the thermal port contribution (`write_zone_thermal_contributions`) — OCHRE explicitly does not scale sensible/latent gains to the envelope (HVAC.py:556-566 comment: "sensible/latent gains to envelope are not updated")
- [ ] Apply `space_fraction` after the ideal-capacity solve, never inside the solver
- [ ] Add tests:
  - `space_fraction=0.5` produces half the electrical power
  - Thermal port is NOT halved (zone sees full cooling)
  - Heat pump heater reads `fraction_heating_load_served`, cooler reads `fraction_cooling_load_served`

## Files to Touch
