## Background/Context

The DER_Detection simulation_explorer shows outdoor temperature on a dual-axis chart alongside net power. HARES tracks `outdoor_temp_c` internally in `EnvironmentState` every timestep but doesn't include it in the `simulate()` output DataFrame at any verbosity level. Currently the explorer parses the EPW file separately as a workaround.

## Work to Do

### `crates/hares-io/src/output/columns.rs`

- [ ] Add column constant: `const OUTDOOR_TEMP_COL: &str = "Outdoor Dry Bulb (C)";`
- [ ] In the verbosity >= 2 block (after zone temperature and unmet load columns, around line 83-94), add:
  ```rust
  fields.push(Field::new(OUTDOOR_TEMP_COL, DataType::Float64, true));
  ```
- [ ] In `expected_columns_at_verbosity()` (if it exists), add the column for verbosity >= 2

### `crates/hares-core/src/dwelling/mod.rs`

- [ ] In `record_step()`, after the zone temperature population block, add:
  ```rust
  if let Some(&idx) = self.output_column_index.get("Outdoor Dry Bulb (C)") {
      row[idx] = self.latest_env.weather.outdoor_temp_c;
  }
  ```
