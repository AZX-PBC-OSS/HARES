## Background/Context

`ScheduleSource::TimeWindows` returns a fixed `f64` per matching window. Real behavioral schedules need noise on top: a WFH driver averages 12 miles on weekdays but with daily variation, 25 miles on weekends with different variation. Currently the only way to get stochastic output is `ScheduleSource::Stochastic`, which has no day/time awareness.

Rather than adding a new variant, extend the existing `TimeWindows` variant with optional seeded noise. When noise is present, the resolved window value becomes the mean of a distribution that's sampled each call. When absent, behavior is unchanged (pure deterministic lookup).

## Work to Do

### Extend `TimeWindow` with optional noise

- [ ] Add optional noise field to `TimeWindow`:
  ```rust
  pub struct TimeWindow {
      pub day: DayFilter,
      pub start_minute: u16,
      pub end_minute: u16,
      pub value: f64,
      /// Optional per-window noise. When set, `value` is the center and the
      /// result is sampled from the distribution each call. When `None`,
      /// `value` is returned exactly (current behavior, zero-cost).
      pub noise: Option<DistributionKind>,
      /// Post-noise output clamp. Prevents nonsensical values (e.g., negative
      /// miles driven from Gaussian noise on a small mean). Applied after
      /// value + noise.sample(). `None` = no clamp on that side.
      pub min_value: Option<f64>,
      pub max_value: Option<f64>,
  }
  ```

- [ ] Update `TimeWindow::new()` to set `noise: None, min_value: None, max_value: None` (backward compatible)

- [ ] Add `TimeWindow::with_noise()` constructor:
  ```rust
  pub fn with_noise(
      day: DayFilter,
      start_minute: u16,
      end_minute: u16,
      value: f64,
      noise: DistributionKind,
      min_value: Option<f64>,
      max_value: Option<f64>,
  ) -> Self
  ```

### Extend `TimeWindows` variant with optional RNG

- [ ] Add optional RNG fields to the `TimeWindows` variant:
  ```rust
  TimeWindows {
      windows: Vec<TimeWindow>,
      default: Option<f64>,
      /// Seeded RNG for windows with noise. `None` when all windows are
      /// deterministic (zero-cost — no RNG allocated).
      rng_state: Option<Box<StochasticState>>,
  },
  ```

- [ ] Define `StochasticState`:
  ```rust
  #[derive(Clone, Debug)]
  pub struct StochasticState {
      pub seed: [u8; 32],
      pub draw_count: u64,
      pub rng: ChaCha8Rng,
  }
  ```

### Update `value_at()` for `TimeWindows`

- [ ] After finding the matching window:
  - If `window.noise` is `None` → return `window.value` (unchanged path, zero cost)
  - If `window.noise` is `Some(dist)` → get the RNG from `rng_state` (error if None — configuration bug), sample from `dist`, compute `raw = value + dist.sample(rng)`, then clamp: `result = raw.clamp(min_value.unwrap_or(f64::NEG_INFINITY), max_value.unwrap_or(f64::INFINITY))`. Increment `draw_count`.
  - The noise is **additive**: result = clamp(value + noise, min, max). For multiplicative noise, use `value = 1.0` and a distribution centered on the desired mean.
  - Clamp applies even to noiseless windows (if `min_value`/`max_value` set) — useful for capping deterministic values too.

### Update `reset()` for `TimeWindows`

- [ ] If `rng_state` is `Some`, re-seed from stored seed and reset `draw_count`

### Update `PartialEq` for `TimeWindows`

- [ ] Include `rng_state` comparison (compare seed + draw_count, ignore rng instance — same pattern as `Stochastic`)

### Convenience constructors on `ScheduleSource`

- [ ] Add helper to create a noisy TimeWindows:
  ```rust
  pub fn noisy_time_windows(
      windows: Vec<TimeWindow>,
      default: Option<f64>,
      seed: [u8; 32],
  ) -> Self
  ```
  Automatically constructs the `rng_state` and validates that at least one window has noise set.

### Unit tests

- [ ] Backward compatible: `TimeWindows` with no noise on any window → `rng_state` is None, values are exact
- [ ] Noisy window: weekday Gaussian(0, 5.0) noise on value=38.0 → samples cluster around 38.0
- [ ] Weekday vs weekend: different noise distributions per window → verify day-dependent sampling
- [ ] Deterministic: two instances with same seed + same call sequence → identical results
- [ ] Different seeds → different results
- [ ] `reset()` → re-produces same sequence from start
- [ ] Mixed: some windows with noise, some without → noiseless windows return exact values
- [ ] No-match with default (no noise on default) → returns exact default
- [ ] Error: window has noise but `rng_state` is None → returns error (not panic)
- [ ] Clamp: value=5.0 with Gaussian(0, 10) noise and min_value=0.0 → never produces negative output (run 1000 samples)
- [ ] Clamp: value=90.0 with Gaussian(0, 20) noise and max_value=100.0 → never exceeds 100
- [ ] Clamp without noise: value=50.0, no noise, min_value=Some(0.0), max_value=Some(100.0) → returns 50.0 exactly

## Example: WFH driver miles schedule

```rust
let miles = ScheduleSource::noisy_time_windows(
    vec![
        TimeWindow::with_noise(
            DayFilter::Weekdays, 0, 1440, 12.0,
            DistributionKind::Gaussian { mean: 0.0, std_dev: 6.0 },
            Some(0.0), None,  // clamp: never negative
        ),
        TimeWindow::with_noise(
            DayFilter::Weekends, 0, 1440, 25.0,
            DistributionKind::Gaussian { mean: 0.0, std_dev: 10.0 },
            Some(0.0), None,  // clamp: never negative
        ),
    ],
    Some(0.0), // default: no driving
    seed,
);
// Weekday: ~12 ± 6 miles (≥ 0). Weekend: ~25 ± 10 miles (≥ 0). Reproducible.
```
