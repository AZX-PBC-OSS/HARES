## Background/Context

The resistance water heater models jacket heat loss internally via
`StratifiedTank::apply_conduction_and_standby()` (UA × (T_node - T_ambient)
per node), but this loss is never written to the thermal port. When the WH
is located in the conditioned zone ("living space"), jacket losses should
warm the zone — OCHRE reports ~39 W for the BEopt example.

## Work to Do

- [ ] In `tank.rs`: expose total jacket loss from the most recent step.
  Add a `last_skin_loss_w: f64` field set during `apply_conduction_and_standby()`.
  Add a `pub fn skin_loss_w(&self) -> f64` accessor.
- [ ] In `resistance.rs` `step()`: after `self.tank.step(...)`, read
  `self.tank.skin_loss_w()` and write to thermal port:
  ```rust
  if let Some(zone) = self.descriptor.zone {
      let skin_loss = self.tank.skin_loss_w();
      if skin_loss.abs() > f64::EPSILON {
          ports.accumulate(&PortContribution::Thermal {
              zone,
              sensible_gain_w: skin_loss,
              latent_gain_w: 0.0,
              category: ThermalCategory::JacketLoss,
          })?;
      }
  }
  ```
- [ ] Add `skin_loss_w` to resistance WH telemetry for observability
- [ ] Add a unit test: tank at 50°C in a 20°C zone with UA=5 W/K should
  produce ~150 W jacket loss. Verify it appears in the thermal port.
