## Background/Context

The Rust Battery equipment reads ~20 config keys (capacity, SOC limits, efficiency, thermal, import/export limits, pack topology), but `PyBattery` only exposes 3: `capacity_kwh`, `max_charge_kw`, `max_discharge_kw`. All other parameters use hardcoded defaults, making it impossible to model specific commercial products from Python.
