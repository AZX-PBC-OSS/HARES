## Background/Context

`finalize()` at line 360-362 computes fixed charges using `bs.period_end()` (the scheduled end of the billing cycle) instead of the actual simulation end time. A simulation ending January 15 gets charged for all 31 days of January.

## Progress

**Session 2026-03-27:**

- [x] Added `finalize()` method to `TariffEvaluator` — returns a final partial billing period summary
- [x] Double-call guard: `reset()` is called after the first `finalize()`, so a second call returns `None`
- [x] Test added: `evaluator_finalize_double_call_returns_none`

Still needed:
- [ ] `finalize()` still uses `bs.period_end()` for fixed charge calculation — charges the full scheduled period even when the simulation ends mid-period. Needs a `sim_end` parameter and `actual_elapsed_days` proration.

## Work to Do

- [x] Create `finalize()` method and add double-call guard via `reset()`
- [ ] Accept actual simulation end timestamp in `finalize()` (add parameter or read from evaluator state)
- [ ] Compute `actual_elapsed_days = (sim_end - bs.period_start()).num_days()` for fixed charge proration
- [ ] Ensure `finalize()` for full-period simulations produces identical results
