## Background/Context

The 15-minute demand window at `evaluator.rs:172` is hardcoded. Some US utilities use 30-minute windows (LADWP commercial) or shorter intervals. Tariffs with non-15-minute windows get incorrect demand charges with no warning.

## Work to Do

- [ ] Add `demand_window_minutes: u32` field to `DemandRate` (or `ElectricTariff`). Default to 15 if not specified
- [ ] Plumb through to `DemandWindow` construction instead of the hardcoded constant
- [ ] Update `DemandWindow::new()` to accept configurable window size

## Files to Touch

- `crates/hares-tariff/src/types.rs`: `demand_window_minutes` field
- `crates/hares-tariff/src/evaluator.rs`: Plumb config to `DemandWindow`
- `crates/hares-tariff/src/billing.rs`: `DemandWindow::new()` accepts window size

## Tests Added

- `demand_window_30_minutes` — configure a 30-minute demand window. Push 30 minutes of samples. Assert `average()` reflects the correct 30-minute window size
- `demand_window_5_minutes` — configure a 5-minute window. Assert 5-minute averaging
- `demand_window_default_15_minutes` — omit `demand_window_minutes`. Assert default 15-minute behavior unchanged (regression guard)
- `demand_window_mid_period_change` — verify demand window is fixed per billing period (no mid-period reconfiguration possible)
