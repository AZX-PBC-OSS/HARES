## Bug

The HPWH model has biquadratic curve coefficients defined as constants (`heat_pump_wh.rs` lines 49-52):

```rust
// heat_pump_wh.rs:49-52
const DEFAULT_COP_CURVE: [f64; 6] = [2.4, 0.03, 0.0, -0.025, 0.0, 0.0];
const DEFAULT_CAPACITY_CURVE: [f64; 6] = [0.563, 0.0437, 0.000039, 0.0055, -0.000148, -0.000145];
```

The model also has ambient lockout bounds (lines 56-62), condenser heat distribution weights (lines 81-83), and a control mode enum (`ElementHpControlMode`, lines 27-35). This suggests significant implementation exists.

However, several critical HPWH-specific behaviors need verification:

1. **COP evaluation:** The COP curve must be evaluated as `f(ambient_wet_bulb_c, tank_avg_temp_c)` each timestep. The state struct has `cop` and `cap_mult` fields (lines 96-97), suggesting this is implemented. Verify the curve is correctly evaluated using `BiquadraticCurve`.

2. **HP priority logic:** The `ElementHpControlMode` enum defines `MutuallyExclusive` and `Simultaneous` modes. Verify that when tank temp drops far below setpoint (high recovery load), the backup element activates appropriately.

3. **Ambient air cooling effect:** HPWH removes heat from surrounding air (acts as an air conditioner in the zone). The `zone_heat_extraction_w` field (line 100) suggests this is tracked. Verify it's injected into the zone's thermal port as a negative sensible gain.

4. **Ambient lockout:** When ambient temperature is below `DEFAULT_MIN_AMBIENT_TEMP_C` (7.2 degC), the compressor should lock out and only the backup element runs. Verify this logic exists.

## OCHRE Reference

OCHRE `Equipment/WaterHeater.py` HPWH-specific features:
- COP = biquadratic(ambient_wet_bulb, tank_avg_temp)
- Capacity = biquadratic(ambient_wet_bulb, tank_avg_temp) * rated_capacity
- HP priority: HP-only below threshold, HP+backup when recovery needed
- Ambient cooling: negative sensible gain to zone = capacity * (1 + 1/COP)
- Ambient lockout: compressor disabled when ambient temp out of range

## Fix

Verify and complete each subsystem:

1. **COP/capacity curves:** Ensure `BiquadraticCurve::evaluate(wet_bulb_c, tank_avg_c)` is called each timestep and the result is used to scale compressor power and heating capacity.
2. **HP priority:** When `tank_avg_temp < setpoint - deadband - backup_enable_offset`, enable backup element per the `ElementHpControlMode`.
3. **Ambient cooling:** Inject `-zone_heat_extraction_w` into the thermal port (negative sensible gain) and appropriate latent gain via SHR split.
4. **Ambient lockout:** When `zone_temp < min_ambient_temp_c || zone_temp > max_ambient_temp_c`, disable compressor.
