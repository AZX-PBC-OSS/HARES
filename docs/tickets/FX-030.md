## Background/Context

HARES uses Spencer (1971) Fourier series with +/-1.5 degree zenith error. OCHRE uses NREL SPA (+/-0.0003 degree). A 1.5 degree error at 80 degree zenith causes ~8.6% beam irradiance error. Matters for peak demand events and DR applications.

## Work to Do

- [ ] Implement NREL SPA algorithm (or Grena simplified SPA, accurate to ±0.01°)
- [ ] Replace `solar_position()` entirely — **do NOT add a `SolarPositionAlgorithm::Spencer` variant or any backward-compat enum**. This is greenfield code; Spencer is dead code with no external callers
- [ ] Include ΔT (TT−UT1) handling: use an appropriate approximation (e.g., ΔT ≈ 69.28s for 2025, from IERS bulletins, or a polynomial fit)
- [ ] Add test: compare SPA output against known NREL validation cases (Denver Oct 17, 2003 case — existing test already has the reference values)
- [ ] Verify existing Perez diffuse model works correctly with SPA inputs
- [ ] Note: the ±1.5° error at 80° zenith causes ~±15% beam irradiance error (not 8.6% as previously stated — that figure applies at ~70° zenith)
