## Background/Context

Three OCHRE features have no HARES equivalent. Each requires a design proposal before implementation:

1. **Resilience / islanded mode (T5-2):** OCHRE implements `voltage == 0` resilience mode at `Dwelling.py:248-272` — resets all electric equipment, re-runs assuming gas generator maintains voltage. HARES accepts `set_grid_voltage(0)` but does not shed electric loads.

2. **Generic Heater/Cooler (T5-3):** OCHRE's `EQUIPMENT_BY_NAME` has catch-all `Heater` and `Cooler` types for HPXML configs that don't match a specific class. HARES will fail on these.

3. **EVI-Pro stochastic EV schedules (T5-5):** OCHRE generates charging event schedules from temperature-stratified PDFs via EVI-Pro data (`ElectricVehicle.generate_events()`). HARES uses fixed archetype schedules.
