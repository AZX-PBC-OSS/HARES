## Status: Complete

## Decision

**Raise `NotImplementedError` immediately.** The action-to-control mapping requires H-7 (action space definition) which is not yet designed. Silently discarding is the worst option. Raising an explicit error ensures RL callers discover the gap at first use, not after a full training run.

## Work Done

- [x] `batch_step()` (internal Rust API): added `assert!(actions.is_empty())` with message referencing H-7
- [x] `batch_step_py()` (Python-exposed API): added pre-check before GIL release that raises `NotImplementedError` if any action vector is non-empty
- [x] Added dimension mismatch check: `ValueError` if `actions.len() != dwellings.len()` (when actions is non-empty)
- [x] Removed both `TODO(H-7)` comments — the error messages now document the gap
- [x] Empty action vectors still work (existing behavior preserved)

## Tests

Tests require Python integration test infrastructure (maturin build + pytest). The behavioral contract is:
- Empty actions → simulation runs normally
- Non-empty actions → `NotImplementedError` with message containing "H-7"
- Wrong-length actions → `ValueError` with dimension info

These should be verified in `tests/python/` when the Python test harness is available.
