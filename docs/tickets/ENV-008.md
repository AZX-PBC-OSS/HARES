## Background/Context

To validate HARES's RC network against OCHRE, we need ground-truth per-boundary data extracted from OCHRE. This script loads the BEopt example through OCHRE and dumps the RC network structure (resistances, capacitances, areas, zone connections, UA values) to JSON for Rust test consumption.

## Work to Do

- [ ] Create `tests/fixtures/parity/extract_ochre_rc.py`:
  - Import OCHRE's Envelope model and load BEopt_example.xml
  - For each boundary in `envelope.boundaries`:
    - Extract: name, label, area, n_nodes, resistors dict, capacitors dict, ext_zone_label, int_zone_label
    - Compute: R_total (sum of resistances / area), UA (area / R_total), total_capacitance
  - For each zone:
    - Extract: name, label, volume, capacitance
  - Compute total dwelling UA: sum of per-boundary UAs
  - Dump to `tests/fixtures/parity/ochre_rc_reference.json` with structure:
    ```json
    {
      "boundaries": [
        {"name": "Exterior Wall", "area_m2": 86.6, "r_total_m2_k_w": ..., "ua_w_k": ..., "capacitance_j_k": ..., "n_nodes": 4, ...},
        ...
      ],
      "zones": [
        {"name": "Indoor", "label": "LIV", "volume_m3": ..., "capacitance_j_k": ...},
        ...
      ],
      "total_ua_w_k": 568.0
    }
    ```
