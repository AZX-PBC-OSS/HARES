# FIX-014: Ground temperature model uses simple sinusoidal, not DOE-2 monthly-damped

> **Clarified** (Codex review 2026-03-19): Proposed fix (monthly-mean amplitude swap) is insufficient. Must implement OCHRE's full DOE-2 method including damping terms (beta, gm, z parameters). Reference: `vendors/OCHRE/ochre/utils/schedule.py:224` for the complete algorithm with all three terms.

**Severity:** HIGH
**Crate:** `hares-io`
**File:** `crates/hares-io/src/epw.rs`

## Bug

HARES implements a DOE-2 sinusoidal correlation for ground temperature (`epw.rs` lines 341-378), but it uses a simple cosine with a fixed phase lag, not the depth-dependent Kusuda-Achenbach model:

```rust
// epw.rs:341-378
/// Compute monthly ground temperatures using the DOE-2 sinusoidal correlation:
///
/// `T_ground(day) = T_avg - T_amp * cos(2π(day - phase) / year_days)`
fn doe2_ground_temp_monthly(dry_bulb_c: &[f64], is_leap_year: bool) -> [f64; 12] {
    // ...
    let t_avg = dry_bulb_c.iter().sum::<f64>() / dry_bulb_c.len() as f64;
    let t_min = dry_bulb_c.iter().cloned().fold(f64::INFINITY, f64::min);
    let t_max = dry_bulb_c.iter().cloned().fold(f64::NEG_INFINITY, f64::max);
    let t_amp = (t_max - t_min) / 2.0;
    // ...
    for (i, &day) in MID_MONTH_DAYS.iter().enumerate() {
        result[i] = t_avg - t_amp * ((day - phase_day) * two_pi_over_year).cos();
    }
}
```

The issue is that `t_amp` uses the hourly min/max range (not monthly average range), which overestimates the amplitude. The Kusuda-Achenbach model includes depth-dependent exponential damping:

`T_ground(z,t) = T_mean - T_amp * exp(-z * sqrt(pi/(365*alpha))) * cos(2pi/365 * (t - t_shift - z/2 * sqrt(365/(pi*alpha))))`

The current implementation has no depth dependency. For foundation heat loss (slab-on-grade), the ground temperature at ~1m depth has significantly damped amplitude compared to surface, which this model misses.

## OCHRE Reference

OCHRE uses a DOE-2 monthly-amplitude-based model where:
1. Monthly average temperatures are computed from hourly data
2. The amplitude uses (max monthly avg - min monthly avg) / 2, NOT (hourly max - hourly min) / 2
3. The phase lag is calibrated to the month of minimum monthly average

Using hourly extremes instead of monthly averages overestimates the ground temperature amplitude by 30-50%.

## Fix

1. Compute monthly average dry-bulb temperatures from the hourly data.
2. Use `t_amp = (max_monthly_avg - min_monthly_avg) / 2.0` instead of `(hourly_max - hourly_min) / 2.0`.
3. Phase lag: use the month index of the minimum monthly average + 30 day lag (not the hour index of the hourly minimum).

```rust
fn doe2_ground_temp_monthly(dry_bulb_c: &[f64], is_leap_year: bool) -> [f64; 12] {
    // Compute monthly averages
    let monthly_avgs = compute_monthly_averages(dry_bulb_c, is_leap_year);
    let t_avg = monthly_avgs.iter().sum::<f64>() / 12.0;
    let t_min_monthly = monthly_avgs.iter().cloned().fold(f64::INFINITY, f64::min);
    let t_max_monthly = monthly_avgs.iter().cloned().fold(f64::NEG_INFINITY, f64::max);
    let t_amp = (t_max_monthly - t_min_monthly) / 2.0;
    // ...
}
```
