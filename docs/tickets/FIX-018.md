# FIX-018: Furnace fan power not derived from fan_power_w_per_cfm

> **REVISED** (Codex review 2026-03-19): AC/HP paths already derive fan power at runtime from `fan_power_w_per_cfm` and airflow/capacity (see `air_conditioner.rs:746`). The real gap is the furnace init path, which ignores `fan_power_w_per_cfm` when no explicit `fan_power_w` is provided.

**Severity:** HIGH
**Crate:** `hares-equipment`
**File:** `crates/hares-equipment/src/hvac/furnace.rs`

---

## Bug

The furnace initialization path does not compute `fan_power_w` from `fan_power_w_per_cfm` when no explicit `fan_power_w` is provided. AC and heat pump paths already handle this correctly at runtime (see `air_conditioner.rs:746`), but the furnace path ignores `fan_power_w_per_cfm` entirely unless `fan_power_w` is explicitly set in config.

When only `fan_power_w_per_cfm` is available (the common ResStock case for furnaces), the furnace model falls back to a default or zero fan power, losing the capacity-scaled fan consumption.

Missing ~400W of auxiliary power for a typical 3-ton furnace system (0.58 W/CFM * 400 CFM/ton * 3 ton = 696W).

## OCHRE Reference

OCHRE computes total fan power from `fan_power_w_per_cfm` for all HVAC equipment types:

```python
fan_power_w = watts_per_cfm * cfm_per_ton * (capacity_btuh / 12000)
```

This applies to furnaces as well as AC/HP equipment.

## Fix

In `furnace.rs` init, when `fan_power_w` is not explicitly provided but `fan_power_w_per_cfm` is available, compute fan power from capacity:

```rust
let fan_power_w = if let Some(w) = first_f64(config, &["fan_power_w"]) {
    w
} else if let Some(w_per_cfm) = first_f64(config, &["fan_power_w_per_cfm"]) {
    let cfm_per_ton = 400.0; // OCHRE default
    let tons = capacity_w / 3_516.85; // W to tons (1 ton = 3516.85 W)
    w_per_cfm * cfm_per_ton * tons
} else {
    DEFAULT_FAN_POWER_W_PER_CFM * 400.0 * (capacity_w / 3_516.85)
};
```

## Test

- **Furnace init with only `fan_power_w_per_cfm`:** Create a 3-ton furnace (10,550 W) with `fan_power_w_per_cfm = 0.58`, no explicit `fan_power_w`. Verify computed `fan_power_w` = 0.58 * 400 * 3 = 696W.
- **Furnace init with explicit `fan_power_w`:** Create with `fan_power_w = 500.0`. Verify it uses 500.0 (explicit takes precedence).
- **Furnace init with neither:** Verify it uses the default `fan_power_w_per_cfm` constant to compute fan power.
- **AC/HP sanity check:** Verify AC and heat pump paths still work correctly (no regression).
