## Background/Context

OCHRE reads `SolarAbsorptance` and `Emittance` for all outdoor-facing boundaries. These drive external surface absorptivity and longwave emissivity. HARES only has `has_radiant_barrier`. Without these, the envelope model uses hardcoded defaults.

## Work to Do

- [ ] Add `solar_absorptance: Option<f64>` and `emittance: Option<f64>` to `Boundary` struct
- [ ] Parse `<SolarAbsorptance>` and `<Emittance>` from HPXML surface elements
- [ ] Apply OCHRE defaults when missing: absorptance=**0.60**, emittance=0.90 for most surfaces; 0.05 for radiant barrier in attic (OCHRE Envelope.py:222 uses 0.60, not 0.70 — EnergyPlus uses 0.70 but we match OCHRE here)
- [ ] Add validation bounds (0.0-1.0)
- [ ] **Wire into solver**: add `solar_absorptance: f64` to `ExteriorSurfaceInfo` in `crates/hares-envelope/src/thermal_solver.rs`; multiply opaque solar gain by absorptance in `apply_solar_inputs`
- [ ] **Wire emittance**: flow parsed `emittance` into `ExteriorSurfaceInfo.emissivity` and `InteriorSurfaceInfo.emissivity` in `crates/hares-core/src/dwelling.rs`, replacing the current `has_radiant_barrier` boolean branch
- [ ] Add tests

## Files to Touch
