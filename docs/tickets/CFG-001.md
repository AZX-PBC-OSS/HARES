## Background/Context

Schedule data passes via 525K individual JSON keys per equipment (~40-80MB each). Multiple crates duplicate lazy schedule enums (PowerScheduleSource, SetpointSource, DeadbandSource). SCHEDULE_DOMAIN_ID defined in 3+ places. This creates the unified replacement.

## Work to Do

- [ ] Create `crates/hares-types/src/schedule.rs`
- [ ] Define `#[non_exhaustive]` `ScheduleSource` enum:
  - `Constant(f64)` — 8 bytes, zero computation
  - `DailyProfile { weekday: [f64;24], weekend: [f64;24], month_multipliers: [f64;12], max_value: f64 }` — 488 bytes inline
  - `ColumnRef { col_idx: usize, boundary: BoundaryPolicy }` — reads from env.custom_domains
  - `SolarAware { daytime_fraction: f64, evening_fraction: f64, overnight_fraction: f64, month_multipliers: [f64;12], max_value: f64, dusk_altitude_threshold_deg: f64 }`
  - `SeededNoise { base: f64, std_dev: f64, seed: [u8;32], rng: ChaCha8Rng }` — deterministic pseudo-random. `seed` stored for `reset()` support.
  - `Shared { data: Arc<[f64]>, cursor: usize, boundary: BoundaryPolicy }` — heap ref for unique data, cursor-based advancement
- [ ] Define `BoundaryPolicy` enum: `Clamp`, `Wrap`, `Error`
- [ ] Implement `value_at(&mut self, env: &EnvironmentState) -> Result<f64, HaresError>` (not `-> f64` — BoundaryPolicy::Error needs error propagation):
  - Stateless variants (Constant, DailyProfile, ColumnRef, SolarAware): pure function of env, idempotent
  - SeededNoise: stateful stepwise RNG — advances exactly once per `value_at()` call. NOT keyed to env.current_time. Determinism = seed + call order.
  - Shared: advance cursor with boundary policy
- [ ] Implement `reset(&mut self)` for checkpoint support
- [ ] Define `SCHEDULE_DOMAIN_ID: DomainId = DomainId(u16::MAX)` — single canonical definition
- [ ] **SeededNoise design**: use stateful stepwise RNG. The RNG advances exactly once per `value_at()` call. Determinism = seed + call order (deterministic in single-threaded sim). Checkpoint = serialize `seed + draw_count` (or full RNG state bytes). `reset()` reconstructs RNG from stored `seed`. NOT keyed to env.current_time.
- [ ] **PartialEq**: implement custom `PartialEq` that compares all fields EXCEPT `rng` (ChaCha8Rng doesn't impl PartialEq). Or skip PartialEq on the enum entirely and note that consumers needing PartialEq must handle it.
- [ ] Derive `Clone, Debug` on ScheduleSource
- [ ] Add `rand`, `rand_chacha` deps to hares-types Cargo.toml
- [ ] Re-export from `crates/hares-types/src/lib.rs`
- [ ] Tests: Constant returns constant, DailyProfile varies by hour/weekday/month, ColumnRef reads from custom_domains, BoundaryPolicy::Wrap wraps, BoundaryPolicy::Error errors, SeededNoise deterministic given seed, Shared cursor advances
