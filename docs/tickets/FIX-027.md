# FIX-027: Heat pump ER hard lockout time defaults to 0

> **STATUS: CLOSED — Invalid** (Codex review 2026-03-19)
> OCHRE's vendored default for ER hard lockout time is 0 minutes (HVAC.py:1214), not 120-300 seconds as the ticket claimed. HARES matching 0 is correct OCHRE parity.

**Severity:** HIGH
**Crate:** `hares-equipment`
**File:** `crates/hares-equipment/src/hvac/heat_pump/heater.rs`

---

## Bug

In `heater.rs` line 458, the emergency resistance hard lockout time defaults to zero:

```rust
// heater.rs:458
self.er_hard_lockout_time_s = first_f64(config, &["er_hard_lockout_time_s"]).unwrap_or(0.0);
```

With `er_hard_lockout_time_s = 0.0`, the emergency/auxiliary resistance heat strips can re-engage immediately after turning off. In a real heat pump system, there is a compressor lockout period (typically 2-5 minutes) before backup resistance can restart. Without this lockout, the simulation allows unrealistic rapid cycling of high-draw resistance elements, which:

1. Overestimates electricity consumption during mild defrost events
2. Produces unrealistic demand spikes in grid impact analysis
3. Can cause numerical oscillations in the thermal solver

## OCHRE Reference

OCHRE `ochre/equipment/hvac.py` defaults emergency resistance lockout time to 120-300 seconds depending on heat pump type. A typical value is 180 seconds (3 minutes). OCHRE never allows immediate re-engagement of backup resistance after shutoff.

## Fix

1. Define a named constant:

```rust
const DEFAULT_ER_HARD_LOCKOUT_TIME_S: f64 = 180.0;
```

2. Replace `.unwrap_or(0.0)`:

```rust
self.er_hard_lockout_time_s = first_f64(config, &["er_hard_lockout_time_s"])
    .unwrap_or(DEFAULT_ER_HARD_LOCKOUT_TIME_S);
```

## Test

- **Unit test:** Create a heat pump heater with no `er_hard_lockout_time_s` in config. Verify default is 180.0.
- **Unit test:** Create a heat pump with explicit `er_hard_lockout_time_s = 300.0`. Verify it uses 300.0.
- **Lockout test:** Turn on ER, then turn it off. Attempt to re-engage within 180 seconds. Verify ER remains off until lockout expires.
- **Lockout test:** Wait 180 seconds after ER off. Verify ER can re-engage.
