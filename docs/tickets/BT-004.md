## Background/Context

`BEAM_FLOOR_FRACTION = 0.60` is hardcoded (solar.rs:11). At high summer solar altitudes in Denver (60°+), a larger fraction of beam solar hits the floor through windows. At low altitudes, more hits walls. EnergyPlus uses geometry-dependent beam distribution.

A fixed 0.60 systematically under-distributes beam to the floor at high altitudes and over-distributes at low altitudes. This affects cooling load distribution in Case 600 (secondary to RC-1 and RC-2, but still contributes).

## Work to Do

### solar.rs

- [ ] Remove the `BEAM_FLOOR_FRACTION` constant (line 11).

- [ ] Add a pure function to compute beam floor fraction from solar altitude:
  ```rust
  fn beam_floor_fraction(solar_altitude_deg: f64) -> f64 {
      solar_altitude_deg.to_radians().sin().clamp(0.3, 0.9)
  }
  ```
  Physics: when the sun is at the horizon (altitude=0°), `sin(0)=0` → clamped to 0.3 (most beam hits walls through windows at shallow angle). At high altitude (90°), `sin(90)=1` → clamped to 0.9 (steep beam through windows hits floor). This is a first-order geometric approximation consistent with EnergyPlus FullInteriorAndExterior.

- [ ] Add `beam_floor_frac: f64` parameter to `compute_solar_distribution_into`:
  ```rust
  pub(crate) fn compute_solar_distribution_into(
      surfaces: &[InteriorSurfaceInfo],
      beam_w: f64,
      diffuse_w: f64,
      beam_floor_frac: f64,  // NEW
      absorbed: &mut Vec<f64>,
  ) -> f64
  ```
  Replace the `BEAM_FLOOR_FRACTION` usage inside with the parameter.

- [ ] Add `solar_altitude_deg: f64` parameter to `distribute_transmitted_solar`:
  ```rust
  fn distribute_transmitted_solar(
      &mut self,
      u: &mut DVector<f64>,
      zone_id: ZoneId,
      beam_w: f64,
      diffuse_w: f64,
      solar_altitude_deg: f64,  // NEW
  ) -> bool
  ```
  Compute `beam_floor_frac = beam_floor_fraction(solar_altitude_deg)` and pass to `compute_solar_distribution_into`.

- [ ] In `apply_solar_inputs` (line 14, has `env: &EnvironmentState`), pass `env.weather.solar_altitude_deg` to `distribute_transmitted_solar` at the call site (line 65).

- [ ] Update the public test helper `compute_solar_distribution` (line ~189) to also accept `beam_floor_frac` and pass it through.
