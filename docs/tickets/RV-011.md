## Background/Context

HVAC speed staging (392 lines) and duct distribution (88 lines) have zero tests. These control compressor staging decisions and distribution system efficiency at every HVAC timestep. Bugs here cascade into incorrect capacity, efficiency, and energy consumption for every HVAC simulation.

## Work to Do

- [x] Add `#[cfg(test)] mod tests` in `staging.rs` covering all public functions
- [x] Add `#[cfg(test)] mod tests` in `duct_distribution.rs`
- [x] Reference AHRI Cd degradation equation for PLF tests
- [x] Use known OCHRE staging behavior as reference where applicable

## Tests Added

**hares-equipment (staging.rs inline tests):**

- `select_speed_single_speed_always_stage_1` — single-speed config. Assert `select_speed` always returns stage 1 regardless of load fraction
- `select_speed_two_speed_setpoint_low_load` — two-speed setpoint mode with load < stage 1 capacity. Assert low speed selected
- `select_speed_two_speed_setpoint_high_load` — load > stage 1 capacity. Assert high speed selected
- `select_speed_two_speed_time_direction_change` — zone temp rising while cooling. Assert speed switches on direction change after minimum time guard
- `select_speed_two_speed_time_min_guard` — attempt speed change before minimum time expires. Assert speed does not change
- `select_multi_speed_interpolation` — 4-speed config with load between stage 2 and 3. Assert correct stage selection
- `part_load_factor_full_load` — PLR = 1.0. Assert PLF = 1.0
- `part_load_factor_half_load` — PLR = 0.5 with known Cd. Assert PLF matches AHRI equation: `1 - Cd * (1 - PLR)`
- `part_load_factor_zero_load` — PLR = 0.0. Assert PLF = minimum (Cd-dependent floor)
- `interpolated_capacity_between_stages` — load fraction between two stages. Assert linear interpolation produces correct capacity
- `interpolated_eir_between_stages` — same for EIR. Assert linear interpolation
- `startup_capacity_degradation_cold_start` — apply degradation to first-minute startup. Assert capacity is reduced by the degradation factor
- `startup_capacity_degradation_warm_restart` — restart within min-cycle time. Assert no degradation applied
- `capacity_fractions_sum_to_one` — for multi-speed config. Assert returned fractions sum to approximately 1.0

**hares-equipment (duct_distribution.rs inline tests):**

- `update_zone_heat_fractions_single_zone` — single zone, no basement. Assert indoor zone fraction = 1.0 - duct loss fraction
- `update_zone_heat_fractions_with_basement` — basement zone present with 30% duct in basement. Assert correct split between indoor and basement zones
- `update_zone_heat_fractions_same_duct_zone` — duct zone == indoor zone. Assert no separate duct loss entry
- `write_zone_thermal_contributions_heating` — positive sensible gain. Assert correct per-zone thermal port writes
- `write_zone_thermal_contributions_cooling` — negative sensible gain. Assert correct sign on cooling contributions
- `apply_duct_dse_scales_capacity` — DSE = 0.8. Assert output capacity is 80% of input capacity
