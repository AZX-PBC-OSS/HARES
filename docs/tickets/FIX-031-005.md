## Background/Context

The envelope oracle test currently compares CSV output columns against OCHRE
reference values. It cannot diagnose per-equipment thermal contributions
because the CSV only shows aggregated values. With the observer framework
capturing per-equipment `EquipmentContribution` (with `ThermalCategory`),
we can write a test that creates a dwelling directly, enables the observer,
runs 60 steps, and checks per-equipment sensible gains against OCHRE.

## Work to Do

- [ ] Add a new test `per_equipment_thermal_contributions` that:
  1. Creates `Dwelling::from_config(beopt_config)` directly
  2. Calls `dwelling.enable_observer(60)`
  3. Runs 60 steps via `dwelling.step()` in a loop
  4. Calls `dwelling.drain_observations()` to get `Vec<StepSnapshot>`
  5. For each snapshot, reads `post_nonthermal_equipment` and
     `post_thermal_equipment` phase captures
  6. Sums per-equipment sensible contributions to ZoneId(1) across all steps
  7. Computes mean per-equipment sensible gain [W]
- [ ] Compare against OCHRE reference (mean over 60 steps):
  | Equipment | OCHRE mean (W) | Tolerance |
  |---|---|---|
  | Indoor Lighting | 62 | 30% |
  | MELs | 98 | 30% |
  | TV | 56 | 30% |
  | Refrigerator | 54 | 30% |
  | Ventilation Fan | 20 | 50% |
  | Water Heater jacket | 39 | 50% |
  | ASHP Heater | ~variable | report only |
  | ASHP Cooler | ~0 | report only |
  | **Total non-HVAC** | **342** | **25%** |
- [ ] Print detailed per-equipment breakdown with OCHRE comparison
- [ ] Assert total non-HVAC internal gains within 25% of OCHRE 342 W
