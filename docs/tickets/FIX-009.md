# FIX-009: COP definition mismatch (fan power in denominator)

> **Architecture note:** HARES Rust core must use clean, typed, SI-unit config keys only. Any OCHRE key/unit translation happens in the Python adapter layer (`python/ochre_next/compat/`). Do not add dual-key lookups or OCHRE naming conventions to Rust code.

**Severity:** HIGH
**Crate:** `hares-equipment`
**File:** `crates/hares-equipment/src/hvac/air_conditioner.rs`

---

## Bug

HARES computes COP = cooling / (compressor + fan). OCHRE computes COP = capacity / (total_input - fan_power). This creates a ~20% reported COP difference for the same equipment.

```rust
// air_conditioner.rs:652-660
// COP = total cooling delivered / compressor electric (excludes crankcase).
let compressor_electric_w = (compressor_kw + fan_kw) * 1000.0;
let total_cooling_w = sensible_cooling_w + latent_cooling_w;
let cop = if compressor_electric_w > 1e-6 {
    total_cooling_w / compressor_electric_w
} else {
    0.0
};
self.telemetry.set("cop", cop);
```

The denominator `(compressor_kw + fan_kw) * 1000.0` includes fan power. OCHRE's COP definition for AHRI/SEER ratings excludes fan power from the denominator.

## OCHRE Reference

OCHRE `Equipment/HVAC.py` computes COP as:

```python
cop = capacity / (total_electric - fan_power)
```

This matches the AHRI/SEER rating definition where COP is compressor-only efficiency.

## Fix

HARES adopts a single COP definition: **COP = capacity / compressor-only electric** (AHRI/SEER convention, excludes fan power from denominator). This is the HARES definition going forward — no toggle, no dual-mode, no config flag to switch between definitions.

Change the denominator to exclude fan power:

```rust
// COP = total cooling / compressor electric only (AHRI/SEER convention)
let compressor_only_w = compressor_kw * 1000.0;
let total_cooling_w = sensible_cooling_w + latent_cooling_w;
let cop = if compressor_only_w > 1e-6 {
    total_cooling_w / compressor_only_w
} else {
    0.0
};
```

Add a separate `total_cop` telemetry field if needed for system-level accounting.

## Test

- Verify edge case: fan_power = 0 -> COP = capacity / total_power.
