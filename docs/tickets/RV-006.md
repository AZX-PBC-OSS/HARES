## Background/Context

`StratifiedTank` allocates 6+ fresh Vecs on every `step()` call:

- `apply_conduction_and_standby()`: `old_temps_c.clone()` + `vec![0.0; n_nodes]`
- `apply_draw()`: `old_temps_c.clone()` + `vec![0.0; n_nodes]`
- `mix_inversions()`: 3 Vecs via `with_capacity(n_nodes)`
- `step()`: `node_temps_c.clone()` for `pre_injection_temps`

At 6 nodes and 1-minute timesteps over 8760 hours, this is ~3.15M heap allocations/year from this one component alone. Node count is fixed after construction so all buffers can be pre-allocated.

## Work to Do

- [ ] Add scratch buffer fields to `StratifiedTank`:
  - `old_temps_scratch: Vec<f64>` (capacity = n_nodes)
  - `conduction_scratch: Vec<f64>` (capacity = n_nodes)
  - `draw_scratch: Vec<f64>` (capacity = n_nodes)
  - `inversion_temps: Vec<f64>` (capacity = n_nodes)
  - `inversion_volumes: Vec<f64>` (capacity = n_nodes)
  - `inversion_counts: Vec<usize>` (capacity = n_nodes)
  - `pre_injection_temps: Vec<f64>` (capacity = n_nodes)
- [ ] Initialize all scratch buffers in `StratifiedTank::new()` with correct capacity
- [ ] In `apply_conduction_and_standby()`: use `old_temps_scratch.copy_from_slice(&self.node_temps_c)` and `conduction_scratch.fill(0.0)` instead of cloning/allocating
- [ ] In `apply_draw()`: reuse scratch buffers similarly
- [ ] In `mix_inversions()`: use `inversion_temps.clear()`, `inversion_volumes.clear()`, `inversion_counts.clear()` + `.push()` to reuse capacity
- [ ] In `step()`: use `pre_injection_temps.copy_from_slice()` instead of `.clone()`
