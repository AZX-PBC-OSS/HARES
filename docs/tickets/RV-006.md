## Background/Context

`StratifiedTank` allocated 6+ fresh Vecs on every `step()` call (~3.15M heap allocations/year at 1-min timesteps). Node count is fixed after construction so all buffers can be pre-allocated.

## Status: **DONE**

- [x] 7 scratch buffer fields added to `StratifiedTank` (tank.rs:92-98), initialized in `new()`.
- [x] `apply_conduction_and_standby()`: uses `copy_from_slice` and `fill(0.0)`.
- [x] `apply_draw()`: reuses scratch buffers.
- [x] `mix_inversions()`: uses `clear()` + `push()` on inversion buffers.
- [x] `step()`: uses `copy_from_slice` for pre-injection temps.
