## Background/Context

ScheduledLoad uses a private `PowerScheduleSource` enum and `schedule: Vec<f64>` (up to 525K elements). Replace both with unified `ScheduleSource` from hares-types, reading compact config keys from CFG-002.

## Work to Do

- [ ] Replace `PowerScheduleSource` with `hares_types::ScheduleSource`
- [ ] In `init_from_config`: read compact keys only:
  - `"column"` -> `ScheduleSource::ColumnRef { col_idx, boundary: BoundaryPolicy::Error }`
  - `"daily_profile"` -> `ScheduleSource::DailyProfile { ... }` from FloatArray config keys
  - `"constant"` -> `ScheduleSource::Constant(kw)`
- [ ] In `step()`: replace `self.schedule[index]` with `self.power_source.value_at(env)`
- [ ] Gas schedule: same treatment with ScheduleSource
- [ ] Remove `schedule: ScheduleRef` field entirely
- [ ] Remove `schedule_index_for_env()` — not needed for ColumnRef/DailyProfile
- [ ] Update `ScheduledLoadState` checkpoint struct to include schedule source state for SeededNoise/Shared variants
- [ ] Update `save_state` / `load_state` — serialize and restore ScheduleSource internal state
- [ ] Add determinism test: save state, restore, verify subsequent values match original trajectory
- [ ] Preserve `stepping_past_schedule_end_returns_error` test — Shared + BoundaryPolicy::Error
- [ ] Delete `PowerScheduleSource` enum definition
- [ ] Delete `ScheduleRef` type alias
- [ ] New test: ScheduledLoad with ColumnRef reads from custom_domains
