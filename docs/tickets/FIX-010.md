# FIX-010: Water heater deadband default mismatch

> **REVISED** (Codex review 2026-03-19): Resistance and HPWH have different deadband defaults in OCHRE. Split into type-specific defaults: 5.56 degC for resistance, 8.17 degC for HPWH.

**Severity:** HIGH
**Crate:** `hares-equipment`
**Files:** `crates/hares-equipment/src/water_heater/resistance.rs`, `crates/hares-equipment/src/water_heater/heat_pump_wh.rs`

---

## Bug

HARES defaults water heater deadband to 2.0 degC in both resistance and heat pump water heaters. Neither value matches OCHRE. OCHRE uses different defaults for each WH type:

- Resistance WH: 10 degF = 5.556 degC
- HPWH: 14.7 degF = 8.167 degC (see `WaterHeater.py:441`)

```rust
// resistance.rs:44
const DEFAULT_DEADBAND_C: f64 = 2.0;

// heat_pump_wh.rs:40
const DEFAULT_DEADBAND_C: f64 = 2.0;
```

With a 2.0 degC deadband, the heater turns on when temp drops 1.0 degC below setpoint and turns off when it reaches 1.0 degC above. The narrower deadband causes more frequent cycling, higher standby losses, and incorrect annual energy consumption. The HPWH deadband is especially wrong (off by 4x) because heat pump compressors have higher startup costs and benefit from wider deadbands.

## OCHRE Reference

OCHRE `Equipment/WaterHeater.py` uses type-specific deadband defaults:

- Resistance WH: deadband = 10 degF = 5.556 degC (general storage WH default)
- HPWH: deadband = 14.7 degF = 8.167 degC (`WaterHeater.py:441`, HPWH-specific default)

## Fix

Set type-specific constants:

```rust
// resistance.rs
const DEFAULT_DEADBAND_C: f64 = 5.555_555_556; // 10°F — OCHRE resistance WH default

// heat_pump_wh.rs
const DEFAULT_DEADBAND_C: f64 = 8.166_666_667; // 14.7°F — OCHRE HPWH-specific default
```

## Test

- **Resistance WH:** Create with no explicit deadband. Verify default is 5.556 degC (not 2.0).
- **Resistance cycle test:** Start at setpoint - 3 degC. Step until element turns on. Verify threshold = setpoint - deadband/2 = setpoint - 2.778 degC.
- **HPWH:** Create with no explicit deadband. Verify default is 8.167 degC (not 2.0, not 5.556).
- **HPWH cycle test:** Start at setpoint - 4 degC. Step until compressor turns on. Verify threshold = setpoint - deadband/2 = setpoint - 4.083 degC.
- **Explicit override:** Create both WH types with explicit deadband = 3.0 degC. Verify both use 3.0 (not the default).
