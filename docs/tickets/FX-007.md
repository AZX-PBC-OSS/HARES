## Background/Context

OCHRE reads `InteriorShading.SummerShadingCoefficient` to reduce effective SHGC. All ResStock files include `<InteriorShading>`. Without this, HARES over-predicts cooling loads.

## Work to Do

- [ ] Add `interior_shading_fraction: Option<f64>` to `Window` struct (doc: this is a transmittance multiplier in [0,1] — fraction of solar that passes through, NOT fraction blocked)
- [ ] Parse `<InteriorShading><SummerShadingCoefficient>` from HPXML
- [ ] **CRITICAL**: Apply as a direct multiplier: `effective_shgc = shgc * shading_fraction` — NOT `shgc * (1 - shading_fraction)`. The `SummerShadingCoefficient` is a transmittance multiplier per ANSI/RESNET/ICC 301-2019: a value of 0.70 means 70% of solar passes through (30% reduction), confirmed by OCHRE `Envelope.py:215`: `window_shgc = kwargs["SHGC (-)"] * kwargs["Shading Fraction (-)"]`
- [ ] When `<InteriorShading>` present but `<SummerShadingCoefficient>` absent: default 0.70 (ANSI/RESNET 301 default)
- [ ] When `<InteriorShading>` absent entirely: apply 1.0 (no shading, unmodified SHGC)
- [ ] Add test asserting `effective_shgc` value (not just that the field is populated): e.g., SHGC=0.40 with shading=0.70 → effective=0.28
- [ ] Note: `WinterShadingCoefficient` is ignored (OCHRE also ignores it — seasonal shading variance is a known simplification)
