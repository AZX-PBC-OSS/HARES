## Background/Context

`compute_eir_from_efficiency` treats HSPF/EER/SEER as dimensionless COP but they are BTU/hr per W. Must divide by 3.412 before computing EIR. For HSPF=8.5: OCHRE gets COP=2.49, EIR=0.401; HARES gets COP=8.5, EIR=0.118 — a 3.4x error.

## Work to Do

- [ ] In `heat_pump/heater.rs:compute_eir_from_efficiency`, read `config.get_str("heating_efficiency_units")` and branch: apply `/ BTU_PER_HR_PER_W` (3.412_141_633) only for `"HSPF" | "EER" | "SEER" | "HSPF2" | "SEER2"` units; leave `"COP" | "AFUE" | "PERCENT"` unconverted
- [ ] Verify `air_conditioner.rs` cooling EIR path — it is **already correct** (`BTU_PER_HR_PER_W / seer` at line 424-431). No code change needed there, only verification
- [ ] Note: `heat_pump/cooler.rs` delegates to `AirConditioner` and is correct by inheritance — no change needed
- [ ] Note: multi-speed path in `hpxml/equipment.rs:1460` uses lookup-table COPs directly (already correct) — unaffected by this fix
- [ ] Add unit tests: HSPF=8.5 → EIR≈0.401, SEER=14 → EIR≈0.244, **and** COP=3.0 → EIR≈0.333 (must NOT be divided by 3.412)
