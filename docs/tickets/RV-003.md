## Status: Complete

## Work Done

- [x] Removed `#[expect(dead_code)]` from `grid_export_rule` field
- [x] Added `clamp_discharge_for_export()` method that enforces export rules:
  - `Unrestricted` → no clamping
  - `Disabled` → discharge clamped to `min(dispatch, base_load)` — no grid export
  - `SolarOnly` → discharge clamped to `min(dispatch, base_load + pv_generation)` — export up to PV only
- [x] Applied clamping at all 3 discharge sites: TOU discharge, DR discharge, Scheduled discharge
- [x] Verified `env.electrical.base_load_kw` and `pv_generation_kw` are available in `EnvironmentState`

## Tests Added

All tests validate actual dispatch power values, not just constructor or type checks:

- [x] `bms_disabled_export_clamps_discharge_to_home_load` — 5 kW battery, 2 kW home load, Disabled rule. Asserts dispatch is exactly -2.0 kW (clamped to load)
- [x] `bms_disabled_export_allows_full_discharge_when_load_exceeds` — 5 kW battery, 8 kW home load, Disabled rule. Asserts dispatch is -5.0 kW (no export, battery just offsetting load)
- [x] `bms_unrestricted_export_no_clamping` — 5 kW battery, 1 kW home load, Unrestricted. Asserts dispatch is -5.0 kW (regression guard)
- [x] `bms_solar_only_export_allows_load_plus_pv` — 5 kW battery, 2 kW load, 1 kW PV, SolarOnly. Asserts dispatch is -3.0 kW (load + PV)
