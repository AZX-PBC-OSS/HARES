## Background/Context

`BatteryManagementActor` accepts `grid_export_rule` in its constructor and stores it as a field, but the field is marked `#[expect(dead_code)]` and is never consulted in `evaluate_mode`. Users who configure `GridExportRule::NoExport` or `GridExportRule::LimitedExport(kw)` will see the battery export without restriction.

## Prerequisite Check

The actor's `decide()` method receives `&EnvironmentState`. Verify that `EnvironmentState` already contains `electrical` data (e.g., `prior_electrical_summary` or `base_load_kw`). If not, the dwelling must populate this field before actor dispatch. Check `dwelling/mod.rs` line ~1979 where `prior_electrical_summary` is computed — this data must be available in `EnvironmentState` by the time actors run. If it is not, add it as part of this ticket's work.

## Work to Do

- [ ] **First:** Verify `EnvironmentState` exposes net home load (e.g., `base_load_kw` or `net_load_kw`). If not, add it — this is required for export clamping. Document the field's semantics (does it include PV? battery? just non-DER load?)
- [ ] Remove `#[expect(dead_code)]` from `grid_export_rule` field
- [ ] In `evaluate_mode`, after computing the raw discharge/export dispatch, clamp the dispatch power according to `grid_export_rule`:
  - `NoExport` → clamp discharge to `min(dispatch_kw, home_load_kw)` — battery can only offset home load, never push to grid
  - `LimitedExport(max_kw)` → clamp discharge to `min(dispatch_kw, home_load_kw + max_kw)` — surplus beyond home load is capped at `max_kw`. Note: when `home_load_kw > dispatch_kw`, the battery is only offsetting load (no export), so no clamping is needed in that case
  - `Unlimited` → no clamp (current behavior)

- `bms_limited_export_rule_clamps_to_limit` — configure `GridExportRule::LimitedExport(2.0)`, scenario with 5 kW excess discharge capacity. Assert dispatch power does not exceed 2.0 kW net export

- `bms_limited_export_load_exceeds_dispatch` — `LimitedExport(1.0)` with home load > dispatch. Assert no clamping (no export occurring)
