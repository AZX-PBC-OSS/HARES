## Background/Context

OCHRE's `get_fnd_wall_insulation` (envelope.py:434-459) performs two operations on foundation walls that HARES doesn't:

1. **Area scaling**: Multiplies wall area by `depth_below_grade / height` when they differ, reducing the effective area for partially below-grade walls.
2. **Insulation detail string**: Generates strings like `"Half R10"`, `"R13"`, or `"Uninsulated"` by analyzing `DistanceToTopOfInsulation` and `DistanceToBottomOfInsulation` from HPXML insulation layers.

**CRITICAL**: OCHRE sets foundation wall `Construction Type = foundation_name` (hpxml.py:408-410), where `foundation_name` comes from the building-level `FoundationType` (e.g., "Unfinished Basement", "Finished Basement", "Crawlspace") — **NOT** from the wall's `WallType`. HARES currently extracts `WallType` which won't match LUT entries.

Without these, the LUT may match the wrong foundation wall R-value variant, and the wall area may be too large.

## Work to Do

- [ ] Parse `foundation_name` from building-level `FoundationType` in `parse_building`:
  - Extract from `<Foundation>/<FoundationType>` (can be dict with keys like "Basement", "Crawlspace", or string like "SlabOnGrade")
  - If `FoundationType` has "Basement" key:
    - If `total_floors > indoor_floors` → `"Finished Basement"`
    - Else → `"Unfinished Basement"`
  - If `FoundationType` has "Crawlspace" key → `"Crawlspace"`
  - If `FoundationType` is "SlabOnGrade", "Ambient", "AboveApartment", or None → `foundation_name = None`
  - Store in `Building.foundation_type: Option<String>`
- [ ] In `parse_boundary` for `BoundaryType::FoundationWall`:
  - Set `construction_type = building.foundation_name.clone()` (from parsed foundation_name above)
  - **Do NOT** use the wall's `WallType` — it won't match LUT entries
- [ ] Add `extract_foundation_wall_insulation(node: &XmlNode, base_area: f64) -> (Option<String>, f64)` to `building.rs`:
  - Parse `Height` and `DepthBelowGrade` from the foundation wall element
  - Compute `area_scale = depth_below_grade / height` when they differ (default: 1.0)
  - Sum `NominalRValue` from all insulation `Layer` elements
  - Parse `DistanceToTopOfInsulation` and `DistanceToBottomOfInsulation` per layer
  - Compute `insulation_height = min(dist_bottom - dist_top)` across layers (default: full wall height)
  - If `insulation_height <= height / 2.0`: format as `"Half R{value}"` (OCHRE convention, no hyphen)
  - Else: format as `"R{value}"`
  - If no insulation: `"Uninsulated"`
  - Return `(insulation_details, area_scale)`
- [ ] In `parse_boundary` for `BoundaryType::FoundationWall`:
  - Set `construction_type` from `building.foundation_name` (already parsed above)
  - Call `extract_foundation_wall_insulation`
  - Set `insulation_details` from the result
  - Multiply `area_m2` by the area scale factor
- [ ] Add unit tests:
  - Full-height R-13 insulation → `"R13"`, scale=1.0
  - Half-height R-10 insulation → `"Half R10"`, scale=1.0
  - Depth below grade 4ft, height 8ft → scale=0.5
  - No insulation → `"Uninsulated"`, scale=1.0
- [ ] Verify format strings match entries in `defaults/envelope/Envelope Boundary Types.csv` for "Foundation Wall"
