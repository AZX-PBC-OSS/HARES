## Background/Context

`PyControlSignal` currently has 3 typed static constructors (`power_setpoint`, `thermal_setpoint`, `soc_target`) plus a generic `from_dict`. The remaining 13 ControlSignal variants require users to construct dicts with string keys. Adding typed constructors for all variants provides type safety and IDE support.

Since PY-005 is a dependency, constructors that take enum values (mode, DR level, inverter priority, duty cycle component) must accept the typed `PyOperatingMode`, `PyDRLevel`, `PyInverterPriority`, `PyDutyCycleComponent` enums from PY-005 — not raw strings. The `from_dict` path should continue to accept strings for backward compat.
