## Background/Context

`PyControlSignal` already has these typed static constructors implemented in `py_control.rs`:
- `power_setpoint` (original)
- `thermal_setpoint` (original)
- `soc_target` (original)
- `thermal_setpoint_delta`
- `ideal_capacity`
- `load_fraction`
- `mode_override` — currently accepts `&str`; must be updated to also accept `PyOperatingMode` from PY-005
- `demand_response` — currently accepts `&str`; must be updated to also accept `PyDRLevel` from PY-005

`from_dict` already parses all 18 ControlSignal variants (including `IdealCapacityModeOverride` and `ThermalSetpointDelta`) via string dispatch.

This ticket adds the 11 remaining typed constructors and `to_dict()`. It also upgrades `mode_override` and `demand_response` to accept the typed enum types from PY-005 in addition to strings.

**New `ControlSignal` variants** that exist in Rust but have no typed constructor yet:
- `IdealCapacityModeOverride { mode: IdealCapacityMode }` — `IdealCapacityMode` has 3 variants: Auto, On, Off
