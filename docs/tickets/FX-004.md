## Background/Context

HARES uses a single `AIRFLOW_DEFAULT_CFM_PER_TON = 375.0` for all HVAC. OCHRE uses 350 for heaters and 312 for coolers. This causes 7-20% fan power error.

## Work to Do

- [ ] Replace single constant with `AIRFLOW_HEATING_CFM_PER_TON = 350.0` and `AIRFLOW_COOLING_CFM_PER_TON = 312.0` (ResStock `hvac.rb` via OCHRE HVAC.py:142). Remove `AIRFLOW_DEFAULT_M3_S_PER_W`
- [ ] Add cooling variants to `HvacEquipmentType`: `AcCooler` (central AC / ASHP cooling coil) and `MiniSplitCool` (MSHP cooling coil). Add `default_airflow_cfm_per_ton(self) -> f64` method that returns 312 for `AcCooler`/`MiniSplitCool`, 350 for all others
- [ ] Update `HvacEquipment::new()` (~line 229) to call `equipment_type.default_airflow_cfm_per_ton()` instead of the old constant
- [ ] Update `HvacEquipment::init()` (~line 294) fallback to call `self.equipment_type.default_airflow_cfm_per_ton()`
- [ ] In `air_conditioner.rs:342`: change `HvacEquipmentType::Other` → `HvacEquipmentType::AcCooler`
- [ ] In `heat_pump/cooler.rs` `HpCooler::build()`: after `AirConditioner::new()`, set `inner.core.hvac.equipment_type = MiniSplitCool` when `is_mshp == true`
- [ ] Extend `plf_cooling_degradation_coeff` match to include `MiniSplitCool` alongside `MiniSplitHeat` for Cd=0
- [ ] Rename test to `airflow_heating_defaults_to_350_and_scales_by_defect_ratio`; add `airflow_cooling_defaults_to_312_and_scales_by_defect_ratio`
- [ ] Boiler `HvacEquipmentType::Other` usages left unchanged — boilers are hydronic, airflow field is unused

## Files to Touch

- `crates/hares-equipment/src/hvac/air_conditioner.rs`: change `Other` → `AcCooler`
