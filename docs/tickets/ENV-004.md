## Background/Context

`resolve_boundary_name` in `envelope_lut.rs` maps `BoundaryType::Floor` with zone pair `(Conditioned, Outdoor)` to the catch-all `_ => Some("Attic Floor")`. The correct LUT boundary name is `"Raised Floor"`. This causes the LUT to match attic floor R-values (high insulation, designed for attic-conditioned boundary) instead of raised floor R-values (designed for conditioned-outdoor boundary), resulting in incorrect thermal resistance.

## Work to Do

- [ ] In `resolve_boundary_name`, add `(ZoneType::Conditioned, ZoneType::Outdoor) => Some("Raised Floor")` to the `BoundaryType::Floor` match arm, before the catch-all:
  ```rust
  BoundaryType::Floor => match (int, ext) {
      (ZoneType::Conditioned, ZoneType::Attic) => Some("Attic Floor"),
      (ZoneType::Conditioned, ZoneType::Foundation) => Some("Foundation Ceiling"),
      (ZoneType::Conditioned, ZoneType::Garage) => Some("Garage Interior Ceiling"),
      (ZoneType::Garage, ZoneType::Attic) => Some("Garage Ceiling"),
      (ZoneType::Conditioned, ZoneType::Outdoor) => Some("Raised Floor"),  // NEW
      _ => Some("Attic Floor"),
  },
  ```
- [ ] Add unit test:
  ```rust
  #[test]
  fn raised_floor_boundary_name() {
      assert_eq!(
          resolve_boundary_name(&BoundaryType::Floor, Some(&ZoneType::Conditioned), Some(&ZoneType::Outdoor)),
          Some("Raised Floor")
      );
  }
  ```
- [ ] Verify "Raised Floor" exists in `defaults/envelope/Envelope Boundary Types.csv` with valid entries
