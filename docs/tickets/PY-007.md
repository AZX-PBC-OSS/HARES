## Background/Context

`SimulationConfig` is currently only constructable via kwargs to `PyDwelling.from_hpxml()`. Users cannot inspect, construct standalone, or share configs between dwellings. Exposing it as a Python type enables config reuse in fleet construction (PY-004) and explicit configuration management.

The Rust `DwellingConfig` struct contains fields beyond `SimulationConfig` that also need exposure: `initialization_duration` and `resample_overrides`.
