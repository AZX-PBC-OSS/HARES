## Background/Context

The verbosity 6 schema defines per-zone columns (Infiltration Heat Gain - Indoor,
Attic, etc.) but only the indoor zone is wired. With per-zone infiltration
tracking (already done in `infiltration.rs`) and per-category port sensible,
we can populate all OCHRE-compatible output columns.

## Work to Do

- [ ] Extend `EnvelopeComponentGains` to store per-zone infiltration:
  ```rust
  pub infiltration_by_zone: Vec<(ZoneId, f64)>,
  ```
  Keep `infiltration_w` for backward compat (alias for indoor zone).
- [ ] In `record_step()`: write per-zone columns when available:
  - `Infiltration Heat Gain - Indoor (W)` — ZoneId(1) infiltration
  - `Infiltration Heat Gain - Attic (W)` — ZoneId(2) if attic exists
  - `Radiation Heat Gain - Indoor (W)` — interior LWR for indoor zone
  - `Radiation Heat Gain - Attic (W)` — interior LWR for attic zone
- [ ] Add columns to verbosity 6 schema for attic zone envelope breakdown
  (only if multi-zone building detected at schema build time).
- [ ] Verify oracle test `Infiltration (indoor)` check now shows the actual
  indoor-zone infiltration value.

## Files to Touch
