## Background/Context

The RC network uses material property lookup tables (wall/roof/floor assembly
thermal resistance, capacitance) loaded from CSV files. These were never compared
against OCHRE's equivalent LUT data.

## Investigation Instructions

1. List all material property LUT CSV files in HARES
2. Find OCHRE equivalents in vendors/OCHRE/ochre/defaults/
3. Compare: same assembly types? Same R-values? Same capacitance values?
4. Check unit consistency (SI in HARES, IP in OCHRE — conversion correct?)
5. Spot-check 5 common assemblies (e.g., "Wood Stud R13", "Interior Wall", "Indoor Furniture")
