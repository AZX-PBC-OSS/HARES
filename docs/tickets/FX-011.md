## Background/Context

HARES injects `SHGC * IAM * POA` as transmitted solar gain but omits the fraction absorbed by the glass itself. For high-SHGC windows (0.6), absorbed glass heat is approximately 15-20 W/m² per unit POA. OCHRE distributes this absorbed fraction partly to the interior zone and partly to the exterior surface node.

## Work to Do

- [ ] Use EnergyPlus Step 4/5 polynomial lookup tables (already partially present in `GlazingCurve::from_u_shgc`) to derive `transmittance` from SHGC and U-factor. **Do NOT use the speculative `0.5 * (1 - SHGC_ratio)` formula** — it has no basis in ASHRAE, EnergyPlus, or OCHRE
- [ ] Compute absorbed fraction: `x = SHGC - transmittance`; derive `absorptivity = x / radiation_frac` (see OCHRE `calculate_window_parameters` in `envelope.py:405-431`)
- [ ] Add `transmittance: f64` and `radiation_frac: f64` fields to `WindowSolarProperties` (pre-computed during config from U-factor and SHGC)
- [ ] Split absorbed heat: interior fraction (`radiation_frac`) goes to zone, exterior fraction (`1 - radiation_frac`) goes to exterior surface node or is explicitly discarded with documentation
- [ ] Change window solar `u[idx]` from overwrite (`=`) to accumulate (`+=`) — also fix opaque path at line 471
- [ ] Add test verifying total solar accounting: `transmitted + absorbed_zone + absorbed_exterior + reflected ≈ incident * area` for a representative SHGC/U combination
