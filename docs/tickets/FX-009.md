## Background/Context

`apply_exterior_longwave_inputs` reads `self.x[info.state_index]` (RC mid-layer node temp) as the surface temp. The true outer-surface temp is separated by material resistances + exterior film resistance. OCHRE solves an iterative coupled system for T_surf accounting for both solar and LWR. For a summer roof, the true surface temp can be 20-30C above the node temp, causing systematic underestimate of outgoing LWR cooling.

## Work to Do

Add four fields to `ExteriorSurfaceInfo` in `thermal_solver.rs`:
```rust
pub rad_frac: f64,      // R_film / (R_film + R_outermost_half) — dimensionless [0,1]
pub rad_res_k_w: f64,   // R_film / area_m2 — K/W
pub n_iter: u32,         // ceil(dt_s / 300.0).max(1)
pub t_prev_c: f64,      // previous-timestep converged surface temp — persistent state
```
Remove `Copy` derive from `ExteriorSurfaceInfo` (keep `Clone`). `t_prev_c` is mutable persistent state.

- [ ] **Compute `rad_frac` and `rad_res_k_w` in `dwelling.rs`** at the `exterior_surfaces.push()` site:
  - `R_film = R_FILM_EXTERIOR_M2_K_W` (0.03 m²·K/W from `boundary_rc.rs`)
  - `R_outermost_half = precomputed_rc.last().resistance_m2_k_w / 2.0` (precomputed path) or `thickness / (2 * conductivity)` (material-layer path)
  - Fallback for single-resistance boundaries: `rad_frac = 0.0`, skip iteration, use node temp directly
  - Initialize `t_prev_c = outdoor_temp_c`

- [ ] **Replace `apply_exterior_longwave_inputs` body** — change signature to `&mut self`. The iterative solver per surface:
  ```
  t_surf_init = rad_frac * t_node + (1 - rad_frac) * t_ext
  for _ in 0..n_iter:
      lwr = e_factor * (svf * t_sky⁴ + (1-svf) * t_ext⁴) - e_factor * t_surf⁴
      t_new = t_surf_init + lwr * rad_res_k_w
      t_new = clamp(t_new, t_surf - 2.0, t_surf + 2.0)       // ±2°C clamp
      t_next = t_surf + 0.5*(t_new - t_surf) + 0.1*(t_surf - t_prev_iter)  // heavy-ball
      if converged (< 0.01°C): break
  info.t_prev_c = t_surf   // persist for next timestep
  u[input_index] += q_lw * rad_frac   // SCALED injection
  ```
  Solar is NOT in the iteration — handled separately in `apply_solar_inputs`. All stack-allocated, zero heap allocation in hot path.

- [ ] **Add `t_prev_c` to checkpoint** `snapshot_state`/`restore_state` — without this, checkpoint restore produces a one-timestep LWR spike

- [ ] Add test comparing converged surface temp against known analytical solution
- [ ] Pre-compute `sky_view_factor` in `ExteriorSurfaceInfo`
