## Background/Context

EventBasedLoad carries `event_window: Vec<f64>` and `event_probability: Vec<f64>` (up to 525K each). Event loads use modulo wrap-around — must use BoundaryPolicy::Wrap to preserve this.

## Work to Do

- [ ] Replace `event_window: Vec<f64>` -> `event_window_source: ScheduleSource`
- [ ] Replace `event_probability: Vec<f64>` -> `event_probability_source: ScheduleSource`
- [ ] In init: read compact keys only:
  - CSV -> `ScheduleSource::ColumnRef { col_idx, boundary: BoundaryPolicy::Wrap }`
  - Flat -> `ScheduleSource::Constant(1.0)` for window
- [ ] Ensure ColumnRef supports wrap semantics in EnvironmentManager's schedule indexing. If EnvironmentManager currently only clamps, add wrap support as part of this ticket.
- [ ] In step: replace `self.event_window[idx]` with `self.event_window_source.value_at(env)`
- [ ] Preserve wrap-around semantics via BoundaryPolicy::Wrap
- [ ] Update save_state/load_state for ScheduleSource state
- [ ] Delete `parse_event_schedule`
- [ ] Apply same to WetAppliance if it shares the pattern
- [ ] All existing event_load tests pass
