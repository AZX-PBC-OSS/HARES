## Background/Context

`GlazingCurve::from_u_shgc()` was called per window surface per step with constant U-factor and SHGC values.

## Status: **DONE**

- [x] Verified immutability: `u_factor_w_m2_k` and `shgc` are never mutated after construction (confirmed by grep).
- [x] `GlazingCurve` precomputed at init and stored as a field on `WindowSolarProperties` (`config.rs:172`).
- [x] `apply_solar_inputs` reads `win.glazing_curve` directly (`solar.rs:23`) — no per-step `from_u_shgc()` call.

## Tests

Correctness guarded by existing 193 hares-envelope tests (including BESTEST cases and window solar gain tests). The refactor changes when computation happens, not what it computes.
