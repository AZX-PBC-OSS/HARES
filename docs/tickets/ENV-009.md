## Background/Context

After all envelope fixes (ENV-002 through ENV-008 and ENV-010) are in place, the diagnostic test from ENV-001 should show HARES's per-boundary UA values closely matching OCHRE. This ticket converts the diagnostic-only test into an asserting test that validates:

1. Total dwelling UA within 10% of OCHRE's reference
2. Per-boundary-name UA within 5% for LUT-matched boundaries
3. Zone capacitances within 1% of OCHRE

Expected acceptable divergences (documented, not failing):
- Film resistances: small difference from TARP/DOE-2 temperature assumptions
- Per-orientation walls vs OCHRE consolidated: same steady-state UA, different node count
- Air density 1.2 vs 1.2041: <0.5%
- Window transmittance interpolation band: HARES 3.4-4.5 vs OCHRE 3.95 threshold
