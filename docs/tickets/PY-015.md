## Background/Context

Each prior ticket (PY-001 through PY-014) updates `_hares.pyi` and `__init__.py` incrementally as it adds new types. This ticket is a final audit pass to catch any remaining gaps, ensure consistency, and verify the complete type surface.

**Note:** This ticket is a review/audit pass, not a bottleneck. Each implementation ticket already updates stubs as part of its own work. This ticket verifies completeness after all implementation is done.

  - Verify parameter types and defaults match `#[pyo3(signature)]` annotations
