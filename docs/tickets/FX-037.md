## Background/Context

All wet appliances and cooking range use `EndUse::Other`, making it impossible to match OCHRE's "Appliances" energy disaggregation. Also, `PowerSetpoint` override on `ScheduledLoad` zeroes gas for dual-fuel equipment (incorrect for gas cooking range with electric ignition).

## Work to Do

- [ ] Add `EndUse::Appliances` variant to the `EndUse` enum in `hares-types/src/equipment.rs`
- [ ] Assign `EndUse::Appliances` to clothes washer, dryer, dishwasher, cooking range in event_load.rs
- [ ] **Fix the gas preservation condition**: use `self.gas_source.is_some()` (not `self.descriptor.fuel == FuelType::Gas`) to decide whether to preserve gas output during `PowerSetpoint`. A dual-fuel cooking range has `FuelType::Electric` as primary fuel but still has a `gas_source` — checking fuel type would still zero the gas
- [ ] Note: Refrigerator/Freezer correctly use `EndUse::Refrigeration` already — not changed
- [ ] Add tests:
  - End-use categorization for all appliance types
  - Dual-fuel `ScheduledLoad` with active `PowerSetpoint`: electric=setpoint, gas=schedule value (not zero)
  - Gas-only `ScheduledLoad` with `PowerSetpoint`: gas preserved
