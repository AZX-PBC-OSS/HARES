# FIX-012: Water heater tank UA doesn't include jacket R-value

> **STATUS: CLOSED — Invalid** (Codex review 2026-03-19)
> Jacket R-value IS already applied via `apply_jacket_r_value()` defined in `water_heater/mod.rs:22` and called in all storage WH models: `resistance.rs:273`, `gas.rs:274`, `heat_pump_wh.rs:411`.

**Severity:** HIGH
**Crate:** `hares-equipment`, `hares-io`
**Files:** `crates/hares-io/src/hpxml/equipment.rs`, `crates/hares-equipment/src/water_heater/tank.rs`

---

## Bug

When HPXML specifies a jacket R-value, HARES extracts it and stores it in the equipment config (`equipment.rs` lines 429-438):

```rust
// equipment.rs:429-438
// Tank jacket R-value
if let Some(jacket_r) = wh
    .path(&["WaterHeaterInsulation", "Jacket", "JacketRValue"])
    .and_then(|n| n.text.trim().parse::<f64>().ok())
{
    // Convert hr·ft²·°F/BTU → m²·K/W
    params.insert(
        "jacket_r_value_m2_k_w".to_string(),
        json!(jacket_r * 0.176_110_184),
    );
}
```

However, a grep for `jacket` in `crates/hares-equipment/src/water_heater/tank.rs` returns zero results. The jacket R-value is stored in the config but never integrated into the tank UA calculation. This means standby losses are ~40% too high for insulated tanks.

The HPWH (`heat_pump_wh.rs` line 18) imports `apply_jacket_r_value` from the water_heater module, suggesting partial implementation exists, but the resistance water heater and tank model don't use it.

## OCHRE Reference

OCHRE `Equipment/WaterHeater.py` incorporates jacket R-value into the effective tank UA:

```python
# UA_total = 1 / (1/UA_tank + R_jacket)
# Series resistance addition
```

## Fix

During tank initialization or config loading:

```rust
// After computing base UA from EF/UEF
if let Some(jacket_r) = first_f64(config, &["jacket_r_value_m2_k_w"]) {
    // Convert jacket R-value to UA adjustment
    // R_jacket is per unit area; multiply by tank surface area
    let tank_surface_area_m2 = tank_surface_area(tank_height_m, tank_diameter_m);
    let ua_jacket = tank_surface_area_m2 / jacket_r;
    // Series resistance: 1/UA_total = 1/UA_tank + 1/UA_jacket
    let ua_combined = 1.0 / (1.0 / ua_base + 1.0 / ua_jacket);
    ua = ua_combined;
}
```

## Test

- Tank with UA=2.0 W/K and jacket R=10 ft2-degF-h/BTU (1.76 m2-K/W): verify combined UA is lower than 2.0.
- **Standby test:** 24hr no-draw. Verify heat loss matches expected with jacket insulation.
- Compare to same test without jacket.
