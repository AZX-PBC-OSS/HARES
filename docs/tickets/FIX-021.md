# FIX-021: PV capacity silently defaults to 0 kW

**Severity:** CRITICAL
**Crate:** `hares-equipment`
**File:** `crates/hares-equipment/src/pv.rs`

---

## Bug

In `pv.rs` lines 135 and 164, PV array capacity defaults to zero when missing:

```rust
// pv.rs:135 (from_single_config)
let capacity_kw = config
    .get_f64(KEY_CAPACITY_KW)
    .or_else(|| config.get_f64(KEY_SYSTEM_SIZE_KW))
    .unwrap_or(0.0);

// pv.rs:164 (from_indexed_config)
let capacity_kw = config
    .get_f64(&key(KEY_CAPACITY_KW))
    .or_else(|| config.get_f64(&key(KEY_SYSTEM_SIZE_KW)))
    .unwrap_or(0.0);
```

A PV system with missing capacity produces zero output for the entire simulation year with no warning or error. This silently eliminates all solar generation from the building model. The `validate` call on line 147 does not reject `capacity_kw == 0.0`.

## OCHRE Reference

OCHRE `ochre/equipment/pv.py` requires `capacity_kw` (or `System Size (kW)`) to be present and positive. If missing, the equipment cannot be initialized and raises a `KeyError`. A PV system with zero capacity is physically meaningless.

## Fix

1. In `PvArray::from_single_config` and `PvArray::from_indexed_config`, replace `.unwrap_or(0.0)` with an explicit error when neither `KEY_CAPACITY_KW` nor `KEY_SYSTEM_SIZE_KW` is found.
2. In `PvArray::validate`, return an error if `capacity_kw <= 0.0`.

```rust
// from_single_config
let capacity_kw = config
    .get_f64(KEY_CAPACITY_KW)
    .or_else(|| config.get_f64(KEY_SYSTEM_SIZE_KW))
    .ok_or_else(|| HaresError::Equipment(
        "PV array requires capacity_kw or system_size_kw (must be > 0)".into(),
    ))?;
```

Apply the same pattern to `from_indexed_config`.

## Test

- **Unit test:** Call `PvArray::from_single_config` with no capacity key. Verify it returns `Err`.
- **Unit test:** Call `PvArray::from_single_config` with `capacity_kw = 0.0`. Verify it returns `Err` (from validation).
- **Unit test:** Call `PvArray::from_single_config` with `capacity_kw = 5.0`. Verify it succeeds and `capacity_kw == 5.0`.
