## Background/Context

`calculate_shr`, `coil_ao_factor`, and `coil_bypass_factor` implement the core cooling-coil psychrometric calculation (apparatus dew point, bypass factor, sensible heat ratio). They contain an iterative root-finding solver with a 50-iteration convergence loop and non-trivial error handling. Currently these have zero unit tests — only indirect coverage through air conditioner integration tests.

## Work to Do

- [ ] Add a `#[cfg(test)] mod tests` block in `coil_physics.rs` with targeted tests for each function
- [ ] Reference ASHRAE Fundamentals coil performance tables or OCHRE's equivalent test vectors for expected values
- [ ] Test boundary conditions: extreme humidity, near-zero airflow, zero capacity
- [ ] Test the non-convergence error path

## Tests Added

**hares-equipment (coil_physics.rs inline tests):**

- `calculate_shr_nominal_cooling` — standard conditions (26.7°C DB, 19.4°C WB, rated flow, rated capacity). Assert SHR within 0.01 of ASHRAE/OCHRE reference value
- `calculate_shr_dry_coil` — very low entering humidity ratio (near `SHR_MIN_HUMIDITY_RATIO`). Assert SHR ≈ 1.0 (all sensible, no latent)
- `calculate_shr_high_humidity` — high entering humidity (W > 0.014 kg/kg). Assert SHR < 0.7 (significant latent removal)
- `calculate_shr_convergence_within_limit` — normal conditions. Assert function returns `Ok` within 50 iterations
- `calculate_shr_non_convergence_error` — craft pathological inputs (near-zero flow, extreme capacity) that prevent convergence. Assert `HaresError::Equipment` is returned with convergence message
- `calculate_shr_zero_capacity_early_return` — pass `q_kw = 0.0`. Assert SHR = 1.0 via the early-return path
- `coil_ao_factor_nominal` — standard inputs. Assert AO factor matches known reference within 1e-6
- `coil_ao_factor_zero_flow` — zero airflow. Assert returns expected value without panic
- `coil_bypass_factor_nominal` — standard inputs. Assert BPF within 0.01 of reference
- `coil_bypass_factor_negative_denominator` — inputs producing near-zero denominator. Assert no panic, reasonable output
- `shr_roundtrip_consistency` — compute AO factor from known BPF, then compute SHR from that AO factor. Assert consistency within solver tolerance
