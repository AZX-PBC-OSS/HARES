# FIX-019: Duct surface area missing for ASHRAE 152 DSE

> **Clarified** (Codex review 2026-03-19): There IS existing partial duct parsing in `building.rs:757` (`parse_duct_systems`). The fix needs to: (1) link HVACDistribution system IDs to equipment IDs first, (2) then extract ASHRAE-152 inputs (surface area, R-value, leakage) from the already-parsed duct data, (3) compute and populate `duct_dse` in equipment config. Don't re-parse — wire existing data.

**Severity:** HIGH
**Crate:** `hares-io`
**File:** `crates/hares-io/src/hpxml/equipment.rs`

---

## Bug

HPXML parsing doesn't extract `DuctSurfaceArea`, `DuctInsulationRValue`, or `DuctLeakageMeasured`, which are needed for ASHRAE 152 Distribution System Efficiency calculation. A grep for `duct` or `DuctSurface` in `equipment.rs` returns zero results related to duct extraction.

The building struct (`hpxml/building.rs`) has a `duct_systems` field on `Zone`, but the equipment parsing that would consume duct data for HVAC DSE calculation does not read these fields.

Without duct surface area and insulation data, the DSE calculation either uses a constant default (1.0 = no duct losses) or is missing entirely, potentially underestimating HVAC energy consumption by 10-30% for poorly insulated duct systems.

## OCHRE Reference

OCHRE extracts from HPXML:
- `DuctSurfaceArea` (supply and return, ft2)
- `DuctInsulationRValue` (supply and return, hr-ft2-F/BTU)
- `DuctLeakageMeasured` or `DuctLeakageValue` (CFM25)
- Duct location (e.g., attic, basement, conditioned space)

These feed into the ASHRAE 152 DSE calculation that adjusts delivered HVAC capacity.

## Fix

1. Extract duct data from HPXML `<AirDistribution>` / `<Ducts>` elements during HVAC resolution:

```rust
if let Some(ducts) = hvac.path(&["HVACDistribution", "DistributionSystemType", "AirDistribution"]) {
    for duct in children_named(ducts, "Ducts") {
        let duct_type = child_text(duct, "DuctType"); // supply / return
        let surface_area_ft2 = child_f64(duct, "DuctSurfaceArea");
        let r_value = child_f64(duct, "DuctInsulationRValue");
        let location = child_text(duct, "DuctLocation");
        let leakage = child_f64(duct, "DuctLeakageMeasured")
            .or_else(|| duct.path(&["DuctLeakageMeasured", "Value"]).and_then(|n| child_f64(n, "Value")));
        // Insert into HVAC equipment params
    }
}
```

2. Pass to HVAC config for DSE calculation.
3. HVAC equipment model uses duct data to compute DSE per ASHRAE 152.
