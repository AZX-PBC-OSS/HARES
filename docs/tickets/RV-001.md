## Status: Complete

## Design Decision

**Return the last valid value when exhausted, not `Option`.** Changing to `Option<T>` is a breaking API change affecting `dwelling/mod.rs:1685-1686` and `py_dwelling.rs:1208-1210`. Instead: when `step_index >= array.len()`, return the last element (clamped index). This is semantically correct (the final price/period persists after simulation ends) and avoids breaking callers. Add a `pub fn is_finished(&self) -> bool` method for callers that need to check.
