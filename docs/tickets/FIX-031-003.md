## Background/Context

The boiler computes fuel consumption with an EIR efficiency curve, writes
fuel and electrical ports, and writes fluid (hot water) output — but never
writes thermal contributions to the zone. The inefficiency fraction
`(1 - 1/EIR) × fuel_input_w` is heat that physically warms the equipment
room. OCHRE includes this as jacket loss.

## Work to Do

- [ ] In `boiler.rs` `step()`: after fuel consumption is computed, calculate
  jacket loss = `fuel_input_w - useful_output_w` (or equivalently
  `fuel_input_w × (1 - efficiency)`). Write to thermal port with
  `ThermalCategory::JacketLoss`.
- [ ] Only write if boiler has a `descriptor.zone` (i.e., indoor installation).
- [ ] Add `jacket_loss_w` to boiler telemetry.
- [ ] Add a unit test verifying jacket loss appears in thermal port.

## Files to Touch

- `crates/hares-equipment/src/hvac/boiler.rs`: Add jacket loss thermal port write
