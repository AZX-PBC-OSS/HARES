## Background/Context

OCHRE reads `ConditionedBuildingVolume` and derives ceiling height as `volume / floor_area`. This drives zone volume calculations, ELA infiltration coefficients, and attic geometry. HARES has no `conditioned_volume_m3` field anywhere.

## Work to Do

- [ ] Add `conditioned_volume_m3: Option<f64>` and `ceiling_height_m: Option<f64>` to `Building` struct
- [ ] Parse `<ConditionedBuildingVolume>` from HPXML (use `VOLUME_FT3_TO_M3` from `crates/hares-physics/src/constants.rs`, do not define a new constant)
- [ ] Derive ceiling height: `volume / conditioned_floor_area`
- [ ] Add `volume_m3: Option<f64>` to `Zone` struct, computed from geometry
- [ ] **Wire parsed volume into `ZoneState`**: update `initial_zones()` in `crates/hares-core/src/environment.rs` to read `zone.volume_m3` instead of `DEFAULT_ZONE_VOLUME_M3` (200.0)
- [ ] **Wire into thermal capacitance**: add `volume_m3: Option<f64>` to `ZoneInput` in `crates/hares-envelope/src/boundary_rc.rs`; update `derive_zone_capacitances()` to prefer it over `floor_area * DEFAULT_HEIGHT_M`
- [ ] **Update `building_to_zone_inputs()`** in `crates/hares-core/src/dwelling.rs` to pass `volume_m3` through to `ZoneInput`
- [ ] Specify fallback when `ConditionedBuildingVolume` absent: use `floor_area_m2 * DEFAULT_HEIGHT_M` with a logged warning
- [ ] Add tests asserting `building.zones[conditioned_idx].volume_m3` is populated AND `ZoneState.volume_m3` is not 200 m³ default
