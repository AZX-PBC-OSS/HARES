## Background/Context

`py_dwelling.rs` `add_ev()` inserts the config key `"max_charging_kw"` (line 631) but the Rust EV config in `ev/config.rs` reads `"max_charging_power_kw"` (line 14, `KEY_MAX_CHARGING_POWER_KW`). The value is silently dropped — every EV added via Python gets the default power (capacity-derived), not the user-specified value. The same bug exists in `py_any_to_equipment()` (line 1056).

## Work to Do

- [ ] In `crates/hares-python/src/py_dwelling.rs`, change `"max_charging_kw"` to `"max_charging_power_kw"` at line ~631 (`add_ev` method)
- [ ] In `crates/hares-python/src/py_dwelling.rs`, change `"max_charging_kw"` to `"max_charging_power_kw"` at line ~1056 (`py_any_to_equipment` method)
- [ ] Add test: create `EV("TestEV", capacity_kwh=60.0, max_charging_kw=3.6)`, add to dwelling, step, verify the EV does not charge faster than 3.6 kW (or verify via equipment descriptors / telemetry that the power matches)
