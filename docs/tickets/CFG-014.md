## Background/Context

After CFG-008 through CFG-013, the typed config migration for built-in equipment
is complete and the resolver name mismatches are fixed. This ticket adds the
permanent test infrastructure that prevents regressions:

1. An exhaustive registry coverage test that fails if any canonical name emitted
   by a resolver is not present in `EquipmentRegistry::new().known_names()`.
   This is AR-005 T-001.

2. A per-struct round-trip test that serializes each typed config to JSON, adds
   an unknown field, and confirms that deserialization returns `Err`. This
   validates that `deny_unknown_fields` is correctly present on every struct.

3. A cross-crate smoke test that constructs one instance of every built-in
   equipment type through the full typed path (resolver → config → init) and
   asserts no panics and no init errors.

These tests are the long-term regression guard for CC-001, CC-003, and CC-005.
Any future change that adds a new equipment type without adding a registry entry
or typed config struct will fail one of these tests.

Fixes (guards against regression): CC-001 (typed config completeness), CC-003
(partial — detects dead keys via round-trip), CC-005 (registry coverage), AR-005
T-001.

### Config round-trip test suite (`crates/hares-io/tests/config_round_trip.rs`)

For each typed config struct (GasFurnaceConfig, ElectricFurnaceConfig,
GasBoilerConfig, ElectricBoilerConfig, ElectricBaseboardConfig, IdealHvacConfig,
CentralAirConditionerConfig, RoomAcConfig, HeatPumpConfig, DehumidifierConfig,
GasWaterHeaterConfig, ElectricResistanceWaterHeaterConfig, TanklessWaterHeaterConfig,
HeatPumpWaterHeaterConfig, BatteryConfig, EvConfig, PvConfig, GeneratorConfig,
VentilationConfig):

- [ ] Add test `round_trip_<struct_name>`:
  ```rust
  let cfg = <StructName> { ..Default::default() /* with realistic non-zero values */ };
  let serialized = serde_json::to_value(&cfg).unwrap();
  let deserialized: StructName = serde_json::from_value(serialized).unwrap();
  assert_eq!(cfg, deserialized);
  ```
- [ ] Add test `deny_unknown_field_<struct_name>`:
  ```rust
  let mut v = serde_json::to_value(&<StructName>::default()).unwrap();
  v["nonexistent_key"] = json!(42.0);
  assert!(serde_json::from_value::<StructName>(v).is_err());
  ```
- [ ] All 19 structs must have both tests.
