## Background/Context

HARES needs shared domain types for battery chemistry, EV charging levels, vehicle types, charging strategies, and plug-in policies. These are genuine domain concepts used across crates — not catalog/product concerns.

Currently `BatteryChemistry`, `ChargingLevel`, and `DriverArchetype` exist only as Python-side enums in `py_enums.rs` with no Rust core counterpart. `DriverArchetype` is being retired entirely (it was an OCHRE legacy hack — behavioral scheduling moves to actors in DER-006/DER-007).

## Work to Do

### Rust: `crates/hares-types/src/equipment.rs`

- [ ] Add `BatteryChemistry` enum with `Nmc`, `Lfp`, `Nca`, `Lto` variants
  - `#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)]`
  - `fn from_str()` (case-insensitive)
  - `impl fmt::Display` (returns "NMC", "LFP", "NCA", "LTO")
  - `fn as_config_str(&self) -> &'static str` — returns lowercase string for equipment config system: `"nmc"`, `"lfp"`, `"nca"`, `"lto"`. Used by DER-003 to convert `PyBatteryChemistry` → config key value, and by DER-004 to parse chemistry from config.

- [ ] Add `ChargingLevel` enum with `L1`, `L2` variants (no `DcFast` — HARES models residential L1/L2 charging only; DCFC is catalog metadata in DER-009)
  - Same derive set
  - `from_str()` / `Display`
  - When refactoring `PyChargingLevel` to wrap this type, remove the `DcFast` variant from the Python enum

- [ ] Add `VehicleType` enum with `Bev`, `Phev` variants
  - Same derive set
  - `from_str()` / `Display`

- [ ] Add `EvConnectionState` enum with `HomePluggedIn` (default), `AwayPluggedIn`, `Disconnected` variants
  - `#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Hash, Serialize, Deserialize)]`
  - Used by EV equipment to distinguish home charging (residential load), away charging (external, no residential load), and disconnected (driving/parked)

- [ ] Add `PlugInPolicy` enum:
  ```rust
  pub enum PlugInPolicy {
      Always,
      LowSoc { threshold: f64 },
  }
  ```
  - Derive `Clone, Debug, PartialEq, Serialize, Deserialize`
  - `from_str()` not needed (structured data, not a simple label)

- [ ] Add `ChargingStrategy` enum:
  ```rust
  pub enum ChargingStrategy {
      Immediate { target_soc: f64 },
      Nightly { off_peak_start_hour: f64, off_peak_end_hour: f64, target_soc: f64 },
      LowSoc { threshold: f64, target_soc: f64 },
      QuickThenWait { partial_soc: f64 },
      PreDeparture { target_soc: f64 },
      TouAware { peak_start_hour: f64, peak_end_hour: f64, target_soc: f64 },
  }
  ```
  - Derive `Clone, Debug, PartialEq, Serialize, Deserialize`
