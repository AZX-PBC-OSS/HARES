# FIX-031: Per-equipment thermal contribution tracking and port separation

## Status: Open

## Problem

Internal heat gain shows 474 W in HARES vs OCHRE 342 W (+38.8%). After subtracting
HVAC thermal output, the non-HVAC contribution is still 132 W too high. We cannot
determine the source because:

1. **Thermal port lumps all contributions** — HVAC, appliances, water heater jacket
   losses, occupancy, and fan heat all accumulate into one `ThermalAccumulator` per zone.
2. **Cross-zone contamination** — `u.iter().sum()` deltas capture all zones combined.
3. **Post-hoc subtraction is fragile** — subtracting HVAC telemetry from total port
   sensible requires matching telemetry keys and assumes no equipment double-writes.

## Equipment thermal audit results

| Equipment | Writes Thermal? | Value | Physical Meaning | Category |
|---|---|---|---|---|
| ASHP Heater | YES | gross thermal_output_w × DSE | Conditioned zone heating | HVAC useful |
| ASHP Cooler | YES | -sensible_cooling_w | Heat removal | HVAC useful |
| Gas Furnace | YES | gross capacity × DSE | Conditioned zone heating | HVAC useful |
| Baseboard | YES | electric output | Direct heating | HVAC useful |
| Boiler | **NO** | — | Jacket losses missing | BUG |
| Scheduled Loads | YES | electric_kw × sensible_fraction | Appliance waste heat | Internal gain |
| Gas WH | YES | jacket loss only | Tank surface losses | Internal gain |
| HPWH | YES | waste heat | Compressor + element waste | Internal gain |
| **Resistance WH** | **NO** | — | Tank jacket losses missing | BUG |
| Battery | YES | ohmic loss | Joule heating | Internal gain |

### Bugs found
- **Boiler** doesn't write jacket/efficiency losses to zone
- **Resistance WH** doesn't write jacket losses to zone (UA × (T_tank - T_zone))

## Approach

### Phase 1: Observer-based per-equipment oracle test

The observer framework (`observer.rs`, `observer_capture.rs`) already captures
per-equipment `EquipmentContribution` with thermal deltas per zone via `diff_ports`.
Write a test that:

1. Creates `Dwelling` directly (not via `SimulationEngine`)
2. Enables observer: `dwelling.enable_observer(60)`
3. Runs 60 timesteps
4. Drains observations and sums per-equipment sensible contributions
5. Compares against OCHRE breakdown:
   - Lighting: 62 W (0.088 kW × 0.70)
   - MELs: 98 W (0.134 kW × 0.73)
   - TV: 56 W (0.076 kW × 0.73)
   - Refrigerator: 54 W (0.054 kW × 1.00)
   - Water heater jacket: 39 W (OCHRE)
   - ASHP Heater: separate (OCHRE 0.91 kWh total heating)
   - Total non-HVAC: ~342 W (OCHRE)

This identifies exactly which equipment contributes the excess 132 W.

### Phase 2: Fix missing equipment thermal contributions

- **Resistance WH**: Compute `UA × (T_avg_tank - T_zone)` each step, write to
  thermal port. The `StratifiedTank` already models this internally.
- **Boiler**: Compute `(1 - efficiency) × fuel_input_w` jacket losses, write to zone.

### Phase 3: Proper port categorization

Add a `ThermalCategory` enum to `PortContribution::Thermal`:
```rust
enum ThermalCategory {
    HvacHeating,      // Intentional zone heating
    HvacCooling,      // Intentional zone cooling
    InternalGain,     // Waste heat from appliances
    JacketLoss,       // Equipment shell losses
    DuctLoss,         // Distribution inefficiency
}
```

This eliminates the need for post-hoc HVAC subtraction — the port knows what
each contribution represents. The thermal solver can accumulate them separately
for output and the observer captures them per-equipment.

### Phase 4: Wire per-zone envelope contributions to output

Use the per-zone infiltration tracking (already done in `infiltration.rs`) and
per-zone port sensible to output OCHRE-compatible columns:
- `Infiltration Heat Gain - Indoor (W)` — conditioned zone only
- `Infiltration Heat Gain - Attic (W)` — attic zone only
- `Internal Heat Gain - Indoor (W)` — InternalGain + JacketLoss for conditioned zone
- `Net Sensible Heat Gain - Indoor (W)` — total conditioned zone from solver
