## Background/Context

`parse_zone_label` at `building.rs:1307` maps the HPXML string `"ground"` to `ZoneType::Outdoor`. Slabs with `<ExteriorAdjacentTo>ground</ExteriorAdjacentTo>` therefore connect to outdoor air temperature instead of ground temperature. This is documented as a known bug in `structural_envelope_oracle.rs:327-336`.

`resolve_exterior` at `conversions.rs:192-195` already maps `Foundation + Slab → ExteriorTarget::Ground`. The fix is to route `"ground"` to `ZoneType::Foundation` so the existing `resolve_exterior` logic catches it.

**Note**: FX-034 proposes a `ZoneType::Ground` enum variant for the same issue. This ticket takes the simpler approach. Coordinate with FX-034 if both are in progress.
