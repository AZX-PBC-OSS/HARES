# FIX-008: PLF bounds missing in biquadratic evaluation

> **STATUS: CLOSED — Invalid** (Codex review 2026-03-19)
> PLF IS already clamped to `[max(0.7, PLR), 1.0]` at `hvac_core.rs:775`. The audit agent only checked the biquadratic bounds constants and missed the PLF evaluation code where clamping is applied.

**Severity:** HIGH
**Crate:** `hares-equipment`
**File:** `crates/hares-equipment/src/hvac/hvac_core.rs`

---

## Bug

OCHRE clamps part-load factor (PLF) between `min_plf` (default 0.7) and `max_plf` (default 1.0). HARES `hvac_core.rs` only has temperature bounds for biquadratic evaluation, no PLF bounds. At low part-load ratios, EIR is unbounded, which overestimates efficiency.

```rust
// hvac_core.rs:38-39 -- only temperature bounds exist
const DEFAULT_BIQUADRATIC_X1_BOUNDS: (f64, f64) = (-100.0, 100.0);
const DEFAULT_BIQUADRATIC_X2_BOUNDS: (f64, f64) = (-100.0, 100.0);
```

The `HvacEquipment` struct (line 192-193) has `plf_cooling_degradation_coeff` and `plf_state` fields, but there is no `plf_bounds` field to clamp the PLF itself:

```rust
// hvac_core.rs:192-193
pub plf_cooling_degradation_coeff: f64,
pub plf_state: f64,
```

When PLR is very low (e.g., 0.2), PLF = 1 - Cd*(1-PLR) = 1 - 0.25*(1-0.2) = 0.8. But at PLR=0.05, PLF = 1 - 0.25*(0.95) = 0.7625. Without a floor, PLF at PLR approaching 0 can go to 1-Cd = 0.75, which is physically plausible, but OCHRE explicitly clamps to [0.7, 1.0] to match AHRI test conditions. The EIR = 1/PLF, so unclamped PLF below 0.7 gives EIR > 1.43, overestimating cycling losses.

## OCHRE Reference

OCHRE `Equipment/HVAC.py` clamps PLF:

```python
plf = max(self.min_plf, min(self.max_plf, plf))
```

Default: `min_plf = 0.7`, `max_plf = 1.0`.

## Fix

Add `plf_bounds: (f64, f64)` field to `HvacEquipment` (default `(0.7, 1.0)`). Clamp PLF before EIR evaluation:

```rust
let plf = (1.0 - cd * (1.0 - plr)).clamp(self.plf_bounds.0, self.plf_bounds.1);
let eir = 1.0 / plf;
```

Load from config:

```rust
self.plf_bounds = (
    extract_numeric(config, "min_plf").unwrap_or(0.7),
    extract_numeric(config, "max_plf").unwrap_or(1.0),
);
```

- Evaluate EIR at PLR=1.0: verify PLF at 1.0.
- Verify COP difference vs unclamped at PLR=0.05.
